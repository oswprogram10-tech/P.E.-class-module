# 농구 동작 이력 안내

기준일: 2026-11-06. S4.5는 교사가 명시적으로 켠 경우에만 READY→SHOOT 감지 요약을 암호화된 이 기기의 학급 데이터에 제한 보관한다. 초기값은 꺼짐이며 유효한 학급·학생·수업·기기 연결이 없으면 기록하지 않는다. 이 이력은 골 성공, 슛 기술의 정확성, 점수나 성적이 아니다.

## 켜기와 확인

교사 PIN으로 학급·학생·수업·기기를 확인하고 동작 이력을 켠다. 녹화 중 필요한 입력 시각, 선택 팔과 민감도, 각도·감지 기준, 전신 gate의 신뢰 요약과 모델 버전만 저장한다. 학생 이름, PIN, 원본 영상, 이미지, 전체 관절 좌표는 기록하지 않는다. 잠금·카메라 중단·화면 이탈·연결 변경 때 기록을 멈춘다. 저장된 이력은 교사 PIN 뒤에서 같은 학급·학생·수업 범위로 조회하거나 삭제할 수 있다.

설정 창의 닫기(X)는 촬영용 PIN 세션을 유지하므로 기록도 계속될 수 있다. 기록을 끝내려면 체크를 끄거나 「잠그기」·촬영 중단을 사용한다. 다음 실행에는 기본 꺼짐이다. 조회 조건은 촬영 학생 지정을 바꾸지 않는다. 조회에는 최근 100건을 표시하며 기기 전체 보관은 최대 2,000건이다. 만료 항목을 정리해도 한도가 가득 차면 새 기록을 중단하고 안내한다. 이전 저장을 처리하는 동안 도착한 기록도 생략을 안내하며 무제한 대기열을 만들지 않는다.

보관은 최대 7일이며 연결된 클립이 있으면 클립 만료일보다 오래 남지 않는다. 클립 연결은 교사의 별도 명시 선택이며 같은 학급·학생·수업과 유효 기간을 확인한다. 이력만으로 영상을 업로드하거나 허브에 보내지 않는다.

기록의 「이 기록 선택」을 누른 뒤 같은 학생·수업·기기의 클립을 고르고 「선택한 클립만 연결」로 확정한다. 클립을 삭제하면 연결한 기록도 삭제된다. 클립 삭제 처리 중 실패한 경우 이력을 다시 읽을 때 남은 연결을 정리한다. 연결하지 않은 독립 기록은 다른 클립을 삭제해도 남는다.

## 개인정보와 한계

이력은 기존 PIN 보호 암호화 로컬 데이터에 저장한다. 만료·수업 자료 삭제·PIN 데이터 초기화는 연결된 이력도 지운다. 저장 용량이 부족하거나 저장 충돌이 나면 기록 실패를 안내하고 촬영은 계속한다. 기록을 위해 유효한 기존 데이터를 조용히 지우지 않는다.

브라우저·fixture 검사는 저장 경계와 데이터 흐름만 확인한다. Android·학교 환경, 40분 연속 사용과 스포츠 동작 정확도는 별도 미검증이다. 자동 허브 전송, 성적 산출, 골 성공 판정은 하지 않는다.
