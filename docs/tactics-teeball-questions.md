# 티볼 사례 검색 질문 v2

개정일: **2026-11-15**

티볼 질문 90개를 15개 유형별로 정리했다. 같은 상황의 표현만 바꾸는 대신 타구 위치·수비 배치·주자·경기 형식을 달리했다. 이 문장은 실제 학생의 발화나 경기 사실이 아니라 새로 작성한 합성 평가 질문이다. 실제 경기 사례는 질문을 작성한 뒤 독립적으로 찾아 검토한다.

공통 기술 질문은 42개, 규칙 확인 후 비교하는 질문은 48개다. 공통 기술에서도 수비 인원·경기장 크기·공의 차이를 표시하고, 규칙 확인이 필요한 질문은 해당 티볼 형식의 규칙과 사례 규칙을 대조하기 전까지 적용 판단을 보류한다. 조건부 분류 자체가 비교 가능성의 확인을 뜻하지 않는다.

기존 투수·번트 중심 유형 `bunt_short_hit`는 정상 타격 뒤 짧은 땅볼 처리 `short_groundball`로, 도루 유형 `base_steal`은 타격 뒤 중계 송구 `relay_throw`로 교체했다. 모든 질문 ID는 이력을 추적하기 위해 유지하되 내용은 `teeball-v2`로 판별한다. 이전 ID의 관련성 판정·평가 결과를 새 질문에 재사용하지 않는다.

질문별 규칙 조건은 [조건 CSV](tactics-teeball-question-context.csv), 임시 카드 후보와 공백은 [5종목 질문 CSV](tactics-query-evaluation.csv)에 기록했다. 조건 CSV는 조사·검토용 문서이며 현재 앱 검색기가 읽는 설정 파일은 아니다.

TE-14-06은 기사 기반 관찰 범위 참고로만 연결해 실제 영상·음성 검증은 보류했다. 기존 연결 재검토와 Luna 추가 조사를 반영한 [질문별 공백 현황](tactics-teeball-coverage.md)에서 비교 근거 상태를 확인한다. 이 표는 티볼 직접 카드 후보만 집계하며 야구 비교 후보는 포함하지 않는다. 수치는 검색 정확도나 데이터 충분성 지표가 아니다.

## 질문 목록

### 01. 외야 깊이 조정 — 공통 기술

비교 조건: 수비 인원·경기장 크기·공의 특성을 확인하고 비교 범위를 외야 깊이와 타구 처리로 한정.

- **TE-01-01** 타자마다 타구가 날아가는 거리가 다른데 우리 외야는 늘 같은 곳에 서요. 타자에 따라 외야가 앞뒤 위치를 바꾼 경기 사례를 찾아주세요.
- **TE-01-02** 외야가 너무 뒤에 서 있어서 앞에 떨어지는 타구를 자주 놓쳐요. 깊은 외야 앞에 타구가 떨어진 경기와 비교하고 싶어요.
- **TE-01-03** 짧은 타구를 막으려고 외야가 앞으로 나왔더니 머리 위로 넘어가는 공이 생겨요. 앞 공간과 뒤 공간을 다르게 지킨 사례가 있을까요?
- **TE-01-04** 이전에 멀리 친 타자가 다시 나왔어요. 앞선 타구를 보고 다음 타석의 외야 위치를 바꾼 사례를 보고 싶어요.
- **TE-01-05** 우리 외야수마다 공을 쫓아가는 속도가 달라요. 선수마다 맡는 범위와 출발 위치를 조정한 경기 장면을 찾아주세요.
- **TE-01-06** 같은 타자가 짧은 타구와 긴 타구를 번갈아 보내요. 외야가 한 가지 타구만 예상했다가 대응한 사례를 비교하고 싶어요.

### 02. 뜬공 뒤 주루·송구 — 규칙 확인 후 비교

비교 조건: 해당 티볼 형식의 뜬공 포구·귀루·재출발 시점·태그업·아웃 판정·플레이 중단 규칙.

- **TE-02-01** 우리 경기는 뜬공 포구 뒤 정해진 절차를 지키면 다시 뛸 수 있어요. 3루 주자의 재출발에 외야 송구로 대응한 사례를 찾아주세요.
- **TE-02-02** 뜬공이 뜨면 주자가 잡힐지 떨어질지 판단하기 어려워해요. 같은 귀루 규칙을 쓰는 경기에서 주자가 멈추거나 돌아간 장면을 보고 싶어요.
- **TE-02-03** 뜬공이 잡히기 전에 주자가 베이스에서 멀리 나가 있어요. 우리 경기의 귀루·아웃 규칙을 확인한 뒤 비교할 사례를 찾아주세요.
- **TE-02-04** 1루와 3루에 주자가 있고 외야수가 뜬공을 잡았어요. 우리와 같은 주루 규칙에서 수비가 어느 주자에게 대응했는지 사례를 보고 싶어요.
- **TE-02-05** 외야수가 뜬공을 잡은 뒤 주자가 다시 뛰려다 멈춰요. 주자와 수비가 서로의 움직임을 보고 판단한 장면이 있을까요?
- **TE-02-06** 우리 티볼의 뜬공 뒤 주루 규칙을 아직 확인하지 못했어요. 태그업 장면을 비교하려면 어떤 규칙이 필요한지 알려주고 확인 전에는 적용 판단을 보류해 주세요.

### 03. 타구와 빈 공간 — 공통 기술

비교 조건: 정지한 공 타격과 실제 경기 타격의 차이를 표시하고 번트가 아닌 정상 타격의 타구·공간만 비교.

- **TE-03-01** 상대 외야가 깊게 서 있어요. 정상적으로 친 낮은 타구가 외야 앞 빈 공간에 떨어진 실제 경기 사례를 찾아주세요.
- **TE-03-02** 우리 타구가 자꾸 높이 떠서 수비에게 잡혀요. 낮게 날아가는 타구와 높은 뜬공의 결과를 함께 비교할 사례가 있을까요?
- **TE-03-03** 상대 수비가 한쪽에 몰려 있어요. 반대쪽 빈 공간으로 정상 타격한 경기 장면과 우리 상황을 비교하고 싶어요.
- **TE-03-04** 타구는 빠른데 늘 수비수 정면으로 가요. 타구 속도보다 방향과 수비 위치가 달랐던 사례를 찾아주세요.
- **TE-03-05** 내야수 뒤와 외야수 앞 사이에 공간이 있어요. 그 사이에 떨어지는 타구를 수비가 어떻게 처리했는지 사례를 보고 싶어요.
- **TE-03-06** 수비가 약한 타구를 예상하고 앞으로 나와 있어요. 정상 타격으로 그 뒤 공간에 공이 간 장면과 비교하고 싶어요.

### 04. 연속 출루·안타 — 규칙 확인 후 비교

비교 조건: 주자 잔류·득점·공수 교대·이닝 종료 방식이 요청 경기와 호환되는지 확인.

- **TE-04-01** 우리 경기는 주자가 남고 홈에 들어오면 점수를 얻어요. 뒤진 이닝에 여러 타자의 안타가 이어져 점수를 낸 사례를 찾아주세요.
- **TE-04-02** 첫 타자가 출루해도 다음 타구에서 주자가 진루하지 못해요. 같은 주루 규칙에서 출루 뒤 진루가 이어진 장면을 보고 싶어요.
- **TE-04-03** 우리 팀은 안타가 여러 번 나와도 주자가 베이스에 남아 득점이 적어요. 안타와 득점 사이의 주루가 확인되는 사례가 있을까요?
- **TE-04-04** 긴 타구 한 번과 짧은 안타 여러 번으로 점수를 낸 흐름을 비교하고 싶어요. 우리와 같은 득점 규칙의 경기 사례를 찾아주세요.
- **TE-04-05** 타자 한 바퀴를 모두 친 뒤 공격을 바꾸는 경기예요. 뒤쪽 타순의 출루가 이어진 실제 티볼 사례가 있을까요?
- **TE-04-06** 안타가 이어지다 주루 아웃으로 공격 흐름이 끊겨요. 같은 아웃·교대 규칙에서 연속 출루가 이어진 경우와 끊긴 경우를 비교하고 싶어요.

### 05. 마지막 이닝·접전 — 규칙 확인 후 비교

비교 조건: 점수·남은 이닝·시간 제한·공수 교대·끝내기 성립 조건을 확인.

- **TE-05-01** 마지막 이닝에 두 점 뒤져 있어요. 마지막 공격에서 출루와 안타가 이어져 역전한 실제 티볼 경기의 흐름을 찾아주세요.
- **TE-05-02** 시간 제한이 가까워졌고 양 팀 점수가 같아요. 마지막 공격의 타격으로 승부가 끝난 티볼 사례를 보고 싶어요.
- **TE-05-03** 마지막 공격에서 주자가 여럿 있지만 남은 아웃이 적어요. 같은 아웃 규칙에서 주자의 진루와 아웃이 확인되는 사례를 찾아주세요.
- **TE-05-04** 초반에 크게 뒤졌지만 마지막 공격까지 점수를 따라갔어요. 이런 흐름이 실제 티볼 경기에서 나온 사례를 비교하고 싶어요.
- **TE-05-05** 전원 타격 뒤 교대하는 경기의 마지막 공격이에요. 아직 칠 학생이 몇 명 남았는지가 중요했던 실제 사례를 찾아주세요.
- **TE-05-06** 마지막 이닝에 한 점 앞선 수비예요. 같은 득점·종료 규칙에서 리드를 지킨 장면과 동점을 허용한 장면을 비교하고 싶어요.

### 06. 실점 뒤 이닝 흐름 — 규칙 확인 후 비교

비교 조건: 이닝·공수 교대·득점 방식 확인; 실점 변화와 실제 수비 조정의 근거를 구별.

- **TE-06-01** 첫 이닝에 많이 실점했지만 다음 이닝부터 실점을 줄인 팀이 궁금해요. 이닝별 점수 흐름이 확인되는 티볼 사례를 찾아주세요.
- **TE-06-02** 한 이닝에 계속 공을 놓친 뒤 수비 위치를 다시 정하고 싶어요. 실제로 위치를 바꾼 과정이 기록된 경기 사례가 있을까요?
- **TE-06-03** 상대 안타가 이어질 때 수비수끼리 공을 받을 위치를 확인해요. 이런 의사소통 뒤의 수비 장면이 기록된 사례를 보고 싶어요.
- **TE-06-04** 한 이닝이 끝난 뒤 수비 역할을 바꿨어요. 같은 경기 인원·교대 규칙에서 역할 변경 전후가 확인되는 사례를 찾아주세요.
- **TE-06-05** 많이 실점한 다음 이닝에 상대를 적은 타자로 막은 티볼 경기의 흐름을 보고 싶어요. 기록에 없는 수비 변화는 추측하지 말아 주세요.
- **TE-06-06** 실점이 줄었다는 결과만 있고 수비가 무엇을 바꿨는지 기록이 없어요. 경기 흐름까지만 비교할 수 있는 사례를 보여주세요.

### 07. 타격 뒤 주자 진루 — 규칙 확인 후 비교

비교 조건: 타격 후 출발·진루·귀루·플레이 중단·홈 득점 규칙 확인.

- **TE-07-01** 공을 친 뒤 외야 앞에 떨어졌는데 1루 주자가 2루에서 멈출지 더 갈지 망설여요. 같은 진루 규칙의 경기 장면을 찾아주세요.
- **TE-07-02** 주자와 베이스 코치의 판단이 달라 주자가 중간에 멈춰요. 타격 뒤 진루 판단과 신호가 확인되는 사례가 있을까요?
- **TE-07-03** 외야수가 공을 잡았을 때 3루 주자가 홈으로 갈지 멈출지 고민해요. 같은 득점·주루 규칙에서 비교할 장면을 보고 싶어요.
- **TE-07-04** 타구가 내야수 사이를 빠져나갔는데 앞 주자가 느려 뒤 주자도 멈춰요. 같은 주루 규칙에서 주자 간 간격이 드러나는 사례를 찾아주세요.
- **TE-07-05** 주자가 타구를 보고 뛰다가 수비 송구를 보고 되돌아가요. 우리 경기의 귀루·플레이 중단 규칙과 맞는 장면이 있을까요?
- **TE-07-06** 우리는 공이 정해진 곳에 돌아오면 플레이를 멈춰요. 그 시점과 주자의 위치가 함께 기록된 티볼 사례만 찾아주세요.

### 08. 포스·태그 아웃 선택 — 규칙 확인 후 비교

비교 조건: 포스 성립·해제·베이스 터치·주자 태그·아웃 순서·득점 인정 규칙 확인.

- **TE-08-01** 1루에 주자가 있고 땅볼이 나왔어요. 우리와 같은 포스 아웃 규칙에서 1루와 2루 중 송구 대상을 고른 사례를 찾아주세요.
- **TE-08-02** 1루와 2루에 주자가 있을 때 내야수가 공을 잡았어요. 어느 베이스에서 아웃을 노렸는지 근거가 있는 장면을 보고 싶어요.
- **TE-08-03** 만루에서 공을 잡은 학생이 홈에 던질지 다른 베이스에 던질지 망설여요. 같은 아웃·득점 규칙의 비교 사례가 있을까요?
- **TE-08-04** 앞에서 달리던 주자를 먼저 아웃시킨 뒤 다음 주자에게 태그가 필요한지 헷갈려요. 포스가 유지되는 조건을 확인할 수 있는 장면을 찾아주세요.
- **TE-08-05** 두 번의 송구로 아웃을 이어가려다 아무도 아웃시키지 못했어요. 우리와 같은 포스·아웃 규칙에서 연속 아웃을 시도한 장면을 비교하고 싶어요.
- **TE-08-06** 우리 수업은 베이스를 밟는 아웃과 주자를 태그하는 아웃을 다르게 정했어요. 규칙을 확인하기 전에는 야구 사례를 그대로 연결하지 말아 주세요.

### 09. 짧은 땅볼 처리 — 공통 기술

비교 조건: 번트가 아닌 정상 타격 뒤 짧은 땅볼; 투수 역할 대신 실제 티볼 수비 위치·인원 확인.

- **TE-09-01** 정상적으로 친 공이 타자 앞쪽으로 짧게 굴러가요. 가까운 내야수들이 공을 잡으러 움직인 실제 경기 장면을 찾아주세요.
- **TE-09-02** 짧은 땅볼에 내야수 두 명이 동시에 달려들어요. 누가 공을 잡고 누가 공을 받을 위치를 맡았는지 확인되는 사례를 보고 싶어요.
- **TE-09-03** 짧은 타구가 1루 쪽으로 굴러가면 공을 잡으러 나온 수비수 뒤가 비어요. 다른 수비수가 빈자리를 맡은 장면이 있을까요?
- **TE-09-04** 짧은 땅볼이 느리게 굴러오면 기다리다가 공을 놓쳐요. 수비수가 앞으로 움직여 타구를 처리한 사례를 비교하고 싶어요.
- **TE-09-05** 약한 땅볼이 수비수 사이로 굴러가는데 서로 상대가 잡을 거라고 생각해요. 공에 먼저 접근할 사람을 정한 장면을 찾아주세요.
- **TE-09-06** 짧은 땅볼이 불규칙하게 튀어서 잡은 뒤 공을 놓쳐요. 타구를 멈추고 다시 확보하는 과정이 보이는 사례를 보고 싶어요.

### 10. 중계 송구 — 공통 기술

비교 조건: 타격 후 살아 있는 공의 중계·연결만 비교; 수비 인원·거리·공의 특성 확인.

- **TE-10-01** 외야수가 멀리 던지기 어려워 공을 한 번에 보내지 못해요. 중간 수비수에게 연결한 경기 장면을 찾아주세요.
- **TE-10-02** 중계할 학생이 너무 가까이 서서 다음 송구 거리가 길어져요. 중계 위치와 두 번의 송구 경로가 확인되는 사례를 보고 싶어요.
- **TE-10-03** 공을 잡은 외야수와 공을 받을 학생 사이에 중계자가 서 있지 않아요. 중계자가 이동해 연결한 장면이 있을까요?
- **TE-10-04** 중계자가 공을 받은 뒤 어느 쪽을 볼지 몰라 몸을 여러 번 돌려요. 공을 받는 방향과 다음 송구가 보이는 사례를 찾아주세요.
- **TE-10-05** 외야 타구가 옆으로 굴러가 처음 정한 중계 위치와 멀어져요. 타구 위치에 맞춰 중계자가 움직인 장면을 비교하고 싶어요.
- **TE-10-06** 중계를 맡은 학생이 송구를 놓쳤을 때 뒤에서 연결할 사람이 없어요. 중계와 백업 역할이 함께 드러난 사례를 찾아주세요.

### 11. 내야 배치·간격 — 공통 기술

비교 조건: 수비 인원·허용 위치·경기장 크기 확인; 배치와 타구 접근 범위만 비교.

- **TE-11-01** 내야수들이 한쪽으로 몰려 반대쪽 공간이 비어요. 타구 방향에 맞춰 간격을 조정한 경기 장면을 찾아주세요.
- **TE-11-02** 약한 타구를 자주 보내는 타자가 나오는데 내야가 너무 뒤에 있어요. 타자에 맞춰 출발 위치를 바꾼 사례가 있을까요?
- **TE-11-03** 빠른 땅볼이 자꾸 내야수 사이로 빠져요. 수비수 사이의 간격과 타구 처리 범위가 보이는 장면을 비교하고 싶어요.
- **TE-11-04** 공이 한 번 옆으로 빠진 뒤 다음 타석에서도 같은 공간이 비어 있어요. 이전 타구를 보고 내야 배치를 바꾼 사례를 찾아주세요.
- **TE-11-05** 우리 팀은 야구 경기보다 수비수가 많아요. 야구의 위치를 그대로 복사하지 않고 빈 공간과 겹치는 범위만 비교할 사례를 보여주세요.
- **TE-11-06** 수비수마다 공을 잡을 수 있는 범위가 달라요. 그 차이를 반영해 내야의 출발 위치를 조정한 장면을 보고 싶어요.

### 12. 송구 판단 — 규칙 확인 후 비교

비교 조건: 주자 위치·포스/태그 아웃·득점·진루 정지 규칙과 실제 송구 목적지 확인.

- **TE-12-01** 내야수가 공을 잡았는데 가까운 베이스와 앞서가는 주자 사이에서 망설여요. 같은 아웃 규칙에서 송구를 선택한 사례를 찾아주세요.
- **TE-12-02** 외야수가 공을 잡자 주자 두 명이 서로 다른 베이스로 뛰어요. 어느 주자에게 송구했는지 확인되는 장면을 보고 싶어요.
- **TE-12-03** 공을 잡은 수비수가 멀리 던지려다 송구가 빗나가요. 같은 주루 규칙에서 가까운 수비수에게 연결한 사례와 비교하고 싶어요.
- **TE-12-04** 주자가 이미 다음 베이스 가까이 왔는데 수비가 늦게 던져요. 송구 시점과 주자 위치를 함께 확인할 수 있는 사례가 있을까요?
- **TE-12-05** 우리 경기는 공을 지정 위치로 돌려보내면 진루가 멈춰요. 주자에게 송구하는 대신 지정 위치로 연결한 실제 티볼 사례를 찾아주세요.
- **TE-12-06** 외야 뜬공을 잡은 뒤 주자가 다시 출발했어요. 우리와 같은 규칙에서 그 주자를 송구로 아웃시킨 티볼 장면을 보고 싶어요.

### 13. 악송구 뒤 백업 — 공통 기술

비교 조건: 백업 위치·공 회수·다음 연결만 비교; 추가 진루나 아웃 효과는 규칙 확인 없이는 판단하지 않음.

- **TE-13-01** 베이스로 보낸 공이 받는 학생 뒤로 빠져요. 송구 뒤쪽을 다른 수비수가 받쳐 준 경기 장면을 찾아주세요.
- **TE-13-02** 송구를 받을 학생이 공을 잡으러 베이스에서 나왔어요. 뒤의 수비수가 어디로 이동했는지 확인되는 사례를 보고 싶어요.
- **TE-13-03** 송구가 옆으로 빗나가면 가까운 학생들이 모두 공을 쫓아가요. 공을 회수할 사람과 다음 연결을 맡을 사람이 구분된 장면이 있을까요?
- **TE-13-04** 중계 송구가 중간에서 빠졌는데 외야수도 멈춰 있어요. 첫 송구 뒤에도 백업을 계속한 사례를 비교하고 싶어요.
- **TE-13-05** 공을 놓친 학생이 혼자 멀리 쫓아가느라 다음에 줄 사람이 없어요. 다른 수비수가 연결 위치로 이동한 사례를 찾아주세요.
- **TE-13-06** 공을 잘 잡는 학생에게만 백업을 맡겨 반대쪽이 비어요. 타구와 송구 방향에 따라 백업을 나눠 맡은 장면을 보고 싶어요.

### 14. 수비 의사소통 — 공통 기술

비교 조건: 콜과 움직임이 실제 출처·영상에서 확인되는지 확인; 보이지 않는 발화를 추정하지 않음.

- **TE-14-01** 두 외야수 사이에 뜬공이 뜨면 서로 잡으러 오다가 멈춰요. 콜과 포구 담당이 확인되는 경기 장면을 찾아주세요.
- **TE-14-02** 내야수 뒤와 외야수 앞 사이의 뜬공에서 둘 다 상대가 잡을 거라고 생각해요. 담당을 정하는 신호가 확인되는 사례가 있을까요?
- **TE-14-03** 공을 잡을 학생은 정했는데 옆 학생도 계속 가까이 와요. 콜 뒤 다른 수비수가 자리를 비켜 주거나 백업한 장면을 보고 싶어요.
- **TE-14-04** 수비수가 공을 잡았는데 어디로 보낼지 알려주는 사람이 없어요. 동료의 신호와 실제 송구 방향이 함께 확인되는 사례를 찾아주세요.
- **TE-14-05** 중계자 여러 명이 서로 공을 달라고 해서 외야수가 망설여요. 한 명이 연결 대상을 알려준 장면이 있을까요?
- **TE-14-06** 영상에는 선수 움직임만 있고 말소리가 들리지 않아요. 움직임으로 확인되는 협력만 설명하고 어떤 말을 했는지는 추측하지 말아 주세요.

### 15. 경기 형식·규칙 확인 — 규칙 확인 후 비교

비교 조건: 요청한 티볼 형식의 규칙 출처·판본을 먼저 확인하고 동일 조건 장면 또는 비교 한계를 기록.

- **TE-15-01** 우리 경기는 타자 전원이 친 뒤 공격을 바꿔요. 3아웃으로 끝나는 경기와 다르다는 점을 표시하고 같은 교대 방식의 티볼 사례를 찾아주세요.
- **TE-15-02** 우리는 세 번째 아웃이 되면 공격을 바꿔요. 남은 아웃 수가 확인되는 티볼 장면을 찾아 같은 규칙 안에서 비교해 주세요.
- **TE-15-03** 우리 경기는 주자가 다음 타석까지 베이스에 남아요. 주자 잔류와 득점 방식이 같은 실제 경기 사례를 찾아주세요.
- **TE-15-04** 우리 수업은 한 번 친 뒤 도달한 베이스 수로 점수를 정해요. 홈에 들어와야 득점하는 경기와 차이를 표시하고 같은 형식의 티볼 장면을 찾아주세요.
- **TE-15-05** 우리는 공이 정해진 위치로 돌아오면 플레이를 멈춰요. 야구의 계속되는 플레이와 구분해서 같은 중단 규칙의 티볼 사례를 보고 싶어요.
- **TE-15-06** 경기 방식이 기억나지 않아 아웃 수나 득점 기준을 설명하기 어려워요. 어떤 규칙을 확인해야 할지 알려주고 조건이 맞는 사례가 없으면 없다고 해 주세요.

## 다음 검토

질문별로 근거 장면이 있는지 확인하고 직접 관련·부분 관련·자료 없음 판정을 사람이 남긴다. 조건부 질문에는 확인한 규칙의 출처와 판본을 붙인다. 야구 비교 자료는 공통 기술 또는 규칙 대조를 마친 장면만 검토하며, 티볼 직접 사례와 구분해 표시한다. 규칙 미확인 질문과 관찰되지 않은 발화를 묻는 질문에서는 필요한 확인이나 근거 부족을 설명하는지 살펴본다.
