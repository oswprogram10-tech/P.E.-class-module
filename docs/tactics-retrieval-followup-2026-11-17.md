# 경기 사례 검색 관련성 보완 (2026-11-17)

단계 5에서 발견한 관련성 결함을 시범 수정하고 검색·구조 검증을 완료했다. 전면·전방 압박을 종목에 맞게 구분하고 라인 사이, 서브에 의한 리시브 흔들림, 후위 수비, 외야 배치, 베이스 선택, 회수 후 복귀, 경기 시작 등 구체 조건을 비교한다. 앞선 타구를 본 뒤 다음 타석의 배치를 조정한 시간·근거 조건은 별도로 미확인 여부를 표시한다. 부정·미관찰 표현과 조건 차이도 비교한다. 한국어로 조건을 표시하며 질문 ID나 평가 연결 목록은 검색 입력에 사용하지 않는다. 표본과 한계는 [독립 검토](tactics-relevance-review-2026-11-17.md)를 따른다.

동일한 450개 문항(75개 상황군, 문항 6개씩이며 티볼은 표현뿐 아니라 경기 조건과 규칙도 다름)으로 [검색 대조](tactics-retrieval-evaluation-2026-11-17.md)와 [답변 구조 검사](tactics-stage5-evidence-contract-2026-11-17.json)를 다시 실행했다. 후보 없음 140문항, 반환 1,751건(중복 포함), 기존 참고목록 하나 이상 발견 246문항이며 서버·브라우저 불일치, 종목 혼합, 차단 자료, 구조상 범위 위반 및 답변 투영 오류는 모두 0이다. 종전 실행의 후보 없음 124문항, 반환 2,019건과 다른 결과지만 기존 참고목록은 검증된 정답이 아니므로 이 숫자는 정확도나 개선율이 아니다. 후보 없음과 미확인 조건의 적절성, 표현과 부정 범위, 남은 의미 관련성은 사람 검토가 필요하다.

기존 자료와 2026-11-15·16 산출물은 보존했다. `node scripts/evaluate-tactics-retrieval.cjs --output-prefix docs/tactics-retrieval-evaluation-2026-11-17`과 `node scripts/evaluate-tactics-answer-contract.cjs --output-prefix docs/tactics-stage5-evidence-contract-2026-11-17`로 별도 기록한다. 평가 질문·목록과 수치 산식은 변경하지 않았다.

이번에는 모델을 호출하지 않았다. 2026-11-16의 실제 모델 실행은 당시 런타임의 역사적 기록이며 현재 검색 변경 후 모델 선택 품질을 검증하지 않는다. 후보 최대 2개, 512 토큰과 엔진 설정을 유지했다. 추천 품질 통과 판단, 전문가 검토, 450회 모델 생성과 Android 실기기·학교 환경 검증은 남아 있다.

독립 단위 테스트 55개도 통과했다. 개발 회귀 확인: 학생 오프라인 검색·한글 조건 표시, 모둠 비교 및 연결된 전술 흐름의 브라우저 검사가 통과했다. Android SDK 35와 Gradle 8.10.2에서 `:app:assembleDebug`, `:app:testDebugUnitTest`, `:app:lintDebug`가 통과했고 생성된 APK의 자산 75개가 현재 저장소 원본과 바이트 단위로 일치했다. 이는 설치·실기기 동작 확인이 아니다.
