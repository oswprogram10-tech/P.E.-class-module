# S5 지원 환경 및 검증 경계

기록 기준일: 2026-11-07. 이 표는 로컬 개발 검증과 실제 기기 지원을 구분한다. Android·학교 현장·발열·실제 40분 연속 사용은 이번 작업에서 제외했다.

| 기능 | 이 세션에서 확인 | 사용 경로 / 대체 | 남은 검증 |
| --- | --- | --- | --- |
| PIN 학급 데이터 | Playwright가 구동한 Chromium, 로컬 HTTP | 현재 PIN의 AES-GCM 저장소에 암호화 | 실제 기기 저장소 압박·화면 전환·기기 분실 정책 |
| PAPS 등급·분포 | 기준 함수 테스트와 Chromium 브라우저 | 학년·평가표 구분을 직접 선택 | 여러 학년도 실제 자료를 이용한 추이 검토 |
| PAPS CSV | 브라우저 다운로드와 단위 테스트 | 확인 후 학생·원자료 선택, 로컬 임시 CSV | 공식 NEIS 양식·필드·문자 제한 없음 |
| 교사 평가·문안 CSV | Chromium 통합, 학생 경계/버전/수식 방지 단위 테스트 | 자체 루브릭, 같은 학생의 승인 평가만 선택 | 공식 교육과정 출처, 실제 행정 출력 검증 |
| 15분 운동 루틴 | 순수 타이머 테스트와 브라우저 시나리오 | 학급 적합성/안전 주의 교사 검토, 체크 없이 시작 불가 | 전문가 검토, 학교 공간·개별 학생 안전 검토 |
| QR 미션 | Chromium offline 수기 ID·순서/퀴즈/저장·익명 응답·미션 단위 삭제 | BarcodeDetector 미지원 또는 카메라 실패 시 ID 수기 입력 | 실물 카메라·기기별 BarcodeDetector 호환 |
| 전술판 | 모델 단위와 Chromium 저장·복제·선택·학급 삭제 | SVG 현재 배치, 좌표 입력, 키보드 접근 | 실제 태블릿 터치/접근성 검토, 기기간 공유 |
| 웨어러블·교구 | 테스트 브리지 v2의 동의 게이트·연결 QR·심박 세션·끊김 공백·워치 수동 QR 재연결; Android 호스트 소스의 TLS 재접속 자격 발급/검증·Wi-Fi 주소 재바인딩·DNS-SD 광고; 가상 자동 복구 흐름. Android 빌드/실기기 미실행 | 학생별 페어링 휴대폰 → 같은 로컬 Wi-Fi → Android 교사 태블릿; QR/TLS 지문 고정/일회성 자격/세션 RAM 전용 전달. Wi-Fi 복구 시 자동 재접속, 주소 변경 시 로컬 탐색 후 QR 안내 | Android 빌드·실제 태블릿 앱, 학생 iOS/Android companion 재시도·서비스 탐색·QR fallback, 모델별 출시일·최소 OS 표, 실기기·OS 권한·학교 시범 |
| PWA 오프라인 | 서비스워커 v22 캐시 전환과 offline 재실행 | 셸을 캐시하고 QR/수기 데이터는 로컬 처리 | 운영 HTTPS 배포·기기별 저장소 회복력 |
| 생성형 AI/GPS/외부 동기화 | 연결하지 않음 | 기능 없음 | 서비스·안전·개인정보·인증 범위를 별도 결정해야 함 |

Chromium 브라우저 검사는 실제 Android·iPad·ChromeOS·Windows 시험을 뜻하지 않는다. 실제 측정/출력과 조직 정책 확인 전에는 제품 지원이나 행정 호환을 주장하지 않는다.
