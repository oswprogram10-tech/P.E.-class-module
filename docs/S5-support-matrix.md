# S5 지원 환경 및 검증 경계

기록 기준일 2026-11-18. 40분 연속 사용·발열·학교 환경 확인은 [교사의 첫 사용 기기·현장 점검](first-use-device-check.md)으로 진행한다. QR·GPS·공유를 사용하는 수업은 아래 현장 확인 절차도 함께 쓴다.

학교 1차 출시 범위는 **교사 기기에 정보 저장 · 학교 서버 운영**이다. 아래 표는 시범 기능을 포함한 개발 검증 기록이며, 웨어러블 정식 연동·공식 PAPS와 나이스·동작 분석과 검토된 콘텐츠·AI의 정식 지원은 첫 출시에서 **미구현**이다. [학교 1차 출시 안내](release-runbook.md)

## S5.9 학교 기기 확인

수업 전 테스트 미션과 익명 전술판으로 확인한다. 기기 모델·OS·브라우저 또는 WebView 버전·앱 버전과 **확인함 / 문제 있음 / 미실행**을 기록한다. 학급 명단·학생 영상·초대 코드·실제 측정 좌표는 점검 기록에 넣지 않는다.

| 직접 실행할 검사 | 확인 기준 |
| --- | --- |
| QR 카메라 허용·거부, QR 포맷 지원과 수동 입력 | 지원 기기에서는 QR로 해당 기기의 미션을 열 수 있다. 거부나 미지원 시 ID를 입력해 같은 미션을 열 수 있다. 화면을 닫거나 앱을 전환하면 QR 카메라가 멈춘다. |
| GPS 허용·거부, 안전 구역 안과 밖 | 교사가 확인한 안전한 실외 구역에서 정지한 상태로 시험한다. 권한 거부·오차 과다·구역 밖에서는 완료가 기록되지 않으며, 도착이 확인되면 완료가 남는다. GPS가 맞지 않는 장소에서는 별도 QR 활동을 사용한다. |
| PWA 또는 APK에서 전술판 초대 | 두 물리 기기에서 신뢰된 학교 HTTPS 주소에 접속해 읽기·편집을 확인한다. 준비한 교사 기기와 학생용 교구가 서로 다른 OS라면 양쪽에서 수행한다. |
| 실제 학교 Wi-Fi 끊김·복귀, 충돌·종료 | 연결을 끊고 로컬 수정본을 보존한다. 복귀 후 게시하고 두 기기가 같은 공유본을 읽는지 확인한다. 다른 배치가 먼저 게시되면 최신 판을 새 사본으로 열어 로컬 수정본과 비교한다. 공유 종료 후 초대 접근이 끝나고 이미 가져온 사본은 유지되는지 확인한다. |

현재 Android는 APK 빌드 수준이다. 실제 Android Chrome·APK, iPad Safari, ChromeOS, Windows 브라우저의 권한과 기능은 해당 기기 시험 결과가 들어올 때 지원표에 기록한다.
