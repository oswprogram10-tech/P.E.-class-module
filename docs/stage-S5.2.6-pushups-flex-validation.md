# S5.2.6 팔굽혀펴기·종합유연성 검증 기록

검증일: 2026-11-07

## 공식 기준 대조

사용자가 제공한 「학교건강검사규칙」 교육부령 제354호 PDF의 SHA-256 `c370d499772929837d35fed32b8d4d8fca195e6e07970b5a8e25efa344bc01e8`을 확인했다.

- 별표 3 PDF 13쪽: 남자는 30cm 높이·110cm 이상 폭의 봉에서 가슴과 봉 사이가 10cm 이하이고 팔꿈치가 90도가 되도록 팔굽혀펴기를 한다. 여자는 무릎을 대고 손 위치를 규정에 맞춰 넓혀 가슴과 바닥 사이 15cm 이하·팔꿈치 90도로 측정한다. 두 방식 모두 더 반복할 수 없을 때까지 횟수를 기록한다.
- 별표 3 PDF 13쪽: 종합유연성은 어깨·몸통·옆구리·하체 네 영역을 오른쪽·왼쪽 한 번씩 확인한다. 한 영역에서 양쪽 성공은 2점, 한쪽 성공은 1점, 모두 실패는 0점이며 네 영역을 더해 0~8점 원점수를 기록한다.
- 별표 4 PDF 17~18쪽: 팔굽혀펴기와 여자 무릎대고 팔굽혀펴기는 초3~초6 미실시이며 해당 중·고 6개 학년 기준만 있다. 종합유연성의 4이하·5·6·7·8점 기준도 중·고 남녀 표에 적용된다. 기존 152개에 남자 팔굽혀펴기 6개, 여자 무릎대고 팔굽혀펴기 6개, 종합유연성 남녀 12개를 더해 전체 176개 기준이다.

## 구현·검증 범위

측정 항목에 남자 팔굽혀펴기, 여자 무릎대고 팔굽혀펴기, 종합유연성을 추가했다. 교사는 측정 학년·평가표 구분을 직접 선택한다. 모델과 화면은 팔굽혀펴기 두 방식의 평가표·학년 적용 범위를 제한하고, 종합유연성은 중·고등학교에서만 입력하게 한다. 각 종목의 규정상 자세/기구 안내와 등급 미리보기를 제공하며 값은 기존 PIN 암호화 로컬 PAPS 흐름으로 저장·보고한다. 종합유연성은 원점수만 기록하고 NEIS용 20점 환산이나 전체 PAPS 점수를 만들지 않는다.

`node --test tests/*.test.cjs`는 133개 전체 단위 검사가 통과했다. 해당 검사에서 공식 176개 기준의 경계·정밀도, 남녀 팔굽혀펴기 기준 분리, 중·고 적용 범위, 종합유연성의 0~8점 등급을 확인했다. Chromium에서는 팔굽혀펴기 두 방식의 안내와 등급, 초등 종합유연성 입력 거부, 중학교 종합유연성 점수·등급, PAPS CSV 흐름을 확인했다.

```text
node tests/browser-classroom-measurements.cjs
PASS 수기 측정·수정 이력·결측·암호화 저장·삭제

node tests/browser-paps-reports.cjs
PASS 팔굽혀펴기 두 방법, 종합유연성 적용 범위·점수·등급,
     추이·분포·선택형 CSV

node tests/browser-pwa.cjs
PASS offline 재시작, 업데이트 대기·자연 활성화, 데이터 보존,
     누락 캐시 자산과 설치 실패 경로
```

서비스워커 앱 셸 캐시는 v26으로 갱신했다. JavaScript 구문 검사와 `git diff --check`도 통과했다.

## 미검증 범위

실제 수업에서의 자세 판정·횟수 계수·종합유연성 영역별 성공 판정은 자동화하지 않았고, 교사 안내를 보고 원점수를 직접 입력한다. 실제 학교 측정·교사 검토·현장 자료는 시험하지 않았다. PAPS 전체 점수·종합등급·BMI 판정·백분위·NEIS 출력은 제공하지 않는다. 게시·배포·commit/push는 하지 않았다.
