# S5.2.5 오래달리기-걷기·스텝검사 검증 기록

검증일: 2026-11-07

## 공식 기준 대조

사용자가 제공한 「학교건강검사규칙」 교육부령 제354호 PDF의 SHA-256 `c370d499772929837d35fed32b8d4d8fca195e6e07970b5a8e25efa344bc01e8`을 재확인했다.

- 별표 3 PDF 11쪽: 오래달리기-걷기는 초등 5·6학년 남녀 1,000m, 중·고 여학생 1,200m, 중·고 남학생 1,600m를 실시한다. 별표 4에 맞춰 시간은 총 초로 입력하게 하고 화면에 `8:00은 480초` 예시를 보여준다.
- 별표 3 PDF 11~12쪽: 스텝검사는 초5·초6 20.3cm/24회·분, 중학생 남녀와 고등 여학생 45.7cm/24회·분, 고등 남학생 50.8cm/30회·분이며 3분 실시한다. 별표 3의 PEI 산식은 성별·학년·심박 측정 방법에 따른 심박수 자료를 사용한다. 이 앱은 심박수 원자료를 수집·저장하거나 PEI를 계산하지 않고, 학교가 규정대로 산출한 PEI 최종 점수만 받는다. 화면은 점수 0.1 단위와 별표 3의 기록 규칙을 안내한다.
- 별표 4 PDF 17~18쪽: 초3·초4는 오래달리기-걷기와 스텝검사를 실시하지 않는다. 오래달리기-걷기 16개 적용 기준(남녀 1,000m 각 2개 학년, 여자 1,200m 6개 학년, 남자 1,600m 6개 학년)과 PEI 16개 기준(초5~고3, 남녀 동일)을 등록했다. 기존 120개를 합쳐 총 152개 적용 기준이다.

## 구현·검증 범위

측정 항목에 1,000m·1,200m·1,600m와 스텝검사 PEI를 추가했다. 측정 학년·평가표 구분을 직접 선택하고 해당 범위에서만 입력하도록 한다. 기록에는 측정 범위와 오래달리기-걷기 거리를 PIN 암호화 로컬 자료로 보존하고, 임시 학생 CSV에도 측정 거리와 측정 범위를 함께 내보낸다. 짧은 달리기 시간이 높은 등급이며, 표 경계와 범위 밖 최저·최고 등급 적용은 전체 기준 검사로 확인했다.

`node --test tests/*.test.cjs`는 131개 전체 단위 검사가 통과했다. 해당 검사는 152개 기준의 적용 가능 범위, 등급 경계, 오래달리기-걷기 역방향 등급, PEI 적용 학년과 정밀도, 규정 프로토콜을 확인한다. Chromium에서는 다음 흐름을 확인했다.

```text
node tests/browser-classroom-measurements.cjs
PASS 수기 측정·수정 이력·결측·암호화 저장·삭제

node tests/browser-paps-reports.cjs
PASS 1,000m 거리/분:초 입력 안내, PEI 프로토콜과 수동 점수 입력,
     등급 미리보기, 추이·분포·선택형 CSV의 측정 범위/거리

node tests/browser-pwa.cjs
PASS offline 재시작, 업데이트 대기·자연 활성화, 데이터 보존,
     누락 캐시 자산과 설치 실패 경로
```

서비스워커 앱 셸 캐시는 v25로 갱신했다. 원문 SHA-256, 변경 파일 JavaScript 구문, `git diff --check`도 통과했다.

## 미검증 범위

실제 수업에서의 거리 측정 정확도, 스텝검사 실시·PEI 산출의 학교 업무 흐름, 실제 학생 자료는 시험하지 않았다. 이 구현은 전체 PAPS 점수·종합등급·BMI·백분위·운동 처방·NEIS 출력을 만들지 않는다. 심박수·운동 지속시간을 앱에 입력하거나 저장하지 않는다. 게시·배포·commit/push는 하지 않았다.
