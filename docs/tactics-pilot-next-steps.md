# 경기 사례 검색 시범의 수용 결정과 남은 구현

**2026-11-17 최신 작업 정책:** AI 구현 단계는 마무리하고 검증은 보류한다. AI 실기기 성능 확인과 AI 선택 품질 검증(전수 모델 생성·전문가 재평가 포함)은 현재 진행 대상에서 제외하여 마지막 통합 검증으로 옮긴다. 이는 검증 완료나 품질 통과를 뜻하지 않으며 추가 학습을 필수 새 작업으로 만들지 않는다. 40분 연속 사용·발열·학교 환경 확인은 기존대로 교사 첫 사용 점검에서 진행한다. 아래의 우선순위와 남은 검증 기록은 당시 이력을 보존한다.

**2026-11-17 응답 준비 개선:** 성공한 기기 AI 실행 후 잠시 모델을 재사용하고 초기화·잠금·화면 종료와 명시적 메모리 비우기에서 해제하도록 연결했다. 실제 앱 3B 단일 측정에서 첫 실행은 변경 전 457.09초, 변경 후 454.60초, 30초 내 동일 질문 재실행은 24.29초였다. 다른 질문의 재사용은 353.40초였다. 각각 Chromium CPU 환경에서 한 번 측정한 결과이며 선택 품질과 학교 기기 검증은 남아 있다. [사용 안내](tactics-speed-guide.md)

**2026-11-17 최신 후보 구성:** 후보 프로파일 구성과 실제 3B 모델 두 문항 실행을 마쳤다. 두 결과 모두 자료의 제한된 부분만 관련되고 요청의 핵심 조건은 확인되지 않았으며, 각각 약 7분 42초~7분 49초가 걸렸다. 응답 속도 개선과 선택 품질 재평가가 남아 있다. [후보 선택 안내](tactics-candidate-selection-guide.md) · [실측 보고서](tactics-candidate-plan-model-2026-11-17.md)

2026-11-17 검색 관련성 시범 수정과 450문항 검색·구조 검증을 완료했다. 추천 품질 통과, 전문가·450회 모델 생성·실기기 검증은 남아 있다. 기존 모델 실행은 이전 런타임의 기록이다. [후속 기록](tactics-retrieval-followup-2026-11-17.md)

갱신일: **2026-11-17**

사용자 요청에 따라 현재 자료 검토는 시범 사용을 위한 수용 단계에서 완료로 처리한다. 결정은 [시범 상태 JSON](tactics-pilot-status.json)에 기록했다. 이 결정으로 시범 구현과 평가를 진행하며, 별도의 전문가 검토를 실제 수행했다는 기록으로 바꾸지 않는다.

## 코드에서 확인한 현재 상태

- 새 조사 묶음은 티볼용 야구 비교 19개와 다른 네 종목 10개, 총 29개 장면 및 122개 임시 연결이다. 이 수치는 독립 경기 수나 승인 정확도를 뜻하지 않는다.
- 앱 서버는 기존 자료에 수용 manifest의 새 조사 JSON과 연결 CSV를 병합한다. 29개 장면과 122개 연결의 조건·한계를 보존한다.
- 검색은 종목을 동일하게 제한하는 BM25 방식과 한글 bigram을 사용한다. 티볼 요청에는 장면 비교 범위와 겹치는 야구 공통 기술 후보만 부분 관련으로 연결한다. 세부 관련성 개선과 평가는 남아 있다.
- 기기 내 WASM 추론 엔진과 3B 모델 설치 경로를 연결했으며, 기존 Ollama 서버 방식도 선택할 수 있다. 실제 기기와 오프라인 재실행 검증 상태는 단계 3 기록을 따른다.
- 제공한 출처 ID만 답변에 허용하고 후보가 없으면 모델을 호출하지 않는 기능은 있다. 부분 관련 근거와 빠진 조건을 표시한다.
- 학생·모둠은 교사 PIN 없이 상황·막힌 점·비교할 점을 입력하고 모델 설치 없이 자료를 검색할 수 있다. 교사 전술판과 기기 모델의 선택 기능도 연결되어 있다. 실제 학교 기기와 수업 검증은 남아 있다.

## 남은 작업 순서

| 단계 | 구현할 내용 | 완료 기준 |
| --- | --- | --- |
| 1. 자료 통합 (완료) | 기존 카드와 새 조사 묶음을 검색용 공통 형식으로 읽고, 사실·근거 위치·부분 관련 조건·시범 수용 상태를 보존 | 새 장면이 실제 앱 검색 후보로 나타나며 원래 종목과 출처를 유지 |
| 2. 검색 조건 연결 (AI 시범 평가 실행, 품질 보완 대기) | 종목·경기 국면·행동·규칙 조건에 따라 후보를 찾고 직접 관련·부분 관련을 구분. 티볼–야구 공통 기술 및 규칙 확인 조건 적용 | 확인되지 않은 규칙이나 행동을 근거로 연결하지 않고 부분 관련의 빠진 조건을 반환 |
| 3. 앱 내 3B 추론 (오프라인 ID 선택 실증, 실기기 검증 대기) | 목표 기기에 맞는 실행 엔진과 3B급 양자화 모델을 정하고, 기기 내 검색 결과를 모델에 전달 | Ollama나 별도 서버 없이 기기 내 생성 가능. 첫 모델 설치 후 네트워크 차단 상태에서도 작동 |
| 4. 학생·모둠 사용 흐름 (개발 검사 완료, 현장 검증 대기) | 기존 전술·막힌 점·원하는 비교를 입력하고 복수 사례와 공통점·차이·근거·한계를 표시. 현재 전술판 흐름과 연결 | 학생/모둠이 요청에서 결과 확인까지 진행하고 연결이 없을 때도 의미 있는 빈 결과를 확인 |
| 5. 검색·답변 평가 (시범 평가 실행 완료, 추천 품질 통과 보류) | 450개 평가 질문으로 검색 누락·출처 일치·종목 혼합·없는 사실 생성·부분 관련 설명을 확인하고 실제 모델 생성도 실행 | 예측 성능이 아니라 실행 기록으로 결과를 확인. 평가 질문은 별도 학습 데이터와 분리 |
| 6. 오프라인 시범 배포 (설치·복구·패키징 개발 검사 완료, 배포 검증 대기) | 모델과 사례 자료의 설치·버전·업데이트·실패 복구를 연결하고 기기에서 설치·재실행·비행기 모드 사용 확인 | 모델과 자료가 준비된 기기에서 외부 서버 없이 재시작 후 사례 검색·비교가 이어짐 |

추가 학습은 5단계의 실제 모델 평가 결과를 보고 필요하면 진행한다. 경기 사실을 외우게 하는 목적보다는 한국어 요청 이해·여러 사례 비교·출처 표시·불확실성 표현을 개선하는 용도로 분리한다. 모델을 더 학습해야만 시범을 시작할 수 있는 구조로 두지 않는다.

단계 2의 조건 기반 후보 분류를 구현했다. 단계 3은 오프라인 Chromium에서 3B ID 선택을 1회 확인했지만 Android 실기기와 실제 수업 속도 검증은 남아 있다. 단계 4의 학생·모둠 입력과 즉시 검색은 브라우저 개발 검사를 통과했으며 현장 검증은 남아 있다. 단계 5는 450문항 검색·구조 검사, 75개 대표 AI 의미감사와 고정 15문항 중 오프라인 실제 생성 10건과 설치 전 온라인 모델 미호출 5건을 확인했다. 추천 품질 통과는 보류하며 450회 모델 생성과 전문가 검토는 하지 않았다. 단계 6은 설치·복구·오프라인 재시작 검색과 Android 패키징 개발 검사를 했으며 실제 기기·배포·업데이트 검증은 남아 있다. 단계 1은 검색 가능 연결을 완료했으며 검색 품질 평가나 전문가 검토 완료를 뜻하지 않는다. 450개 질문은 여섯 표현처럼 유사한 문장이 포함된 평가 묶음이므로 질문 수만으로 경기 상황의 다양성이나 모델 학습 충분성을 판단하지 않는다.


단계 1 개발 확인: `node --test tests/tactics-pilot.test.cjs tests/tactics-sharing.test.cjs tests/tactics-board.test.cjs` 18개 통과, `node tests/browser-connected-tactics.cjs` 모의 로컬 모델 브라우저 흐름 통과. 29개 사례와 122개 연결의 로딩 수를 검사했다. 이는 실제 모델 품질이나 450개 평가 질문의 검색 성능을 검증한 결과가 아니다.


단계 2는 요청과 출처의 관찰된 행동 조건을 비교하고 해당 연결만 부분 관련으로 표시한다. 규칙을 묻는 조건은 확인되지 않은 것으로 표시하며 규칙만 묻는 티볼 요청에 야구 자료를 사용하지 않는다. 검색은 어휘·개념 규칙에 의존하므로 실제 문장 해석과 누락은 단계 5에서 평가해야 한다. 자세한 설계와 검사는 [단계 2 기록](tactics-pilot-stage2-search.md)을 따른다.


단계 5 검색 대조는 [450문항 실행 기록](tactics-retrieval-evaluation-2026-11-15.md)에 있다. 전문가 정답 정확도나 모델 답변 평가가 아니다. 단계 3 실행 방법과 라이선스·기기 조건은 [기기 내 실행 안내](tactics-pilot-stage3-device.md)를 따른다. 3B 자유서술은 사실 혼동과 잘린 설명으로 실패했다. 이후 모델을 ID 선택으로 제한하고 원자료가 설명을 제공하도록 변경하여 오프라인에서 1회 검증했다. 고정 표본에서 실제 선택과 지연을 관찰했으나 의미 정확도를 검증한 것은 아니다. Android 실기기와 수업 사용성은 아직 검증하지 않았다.


2026-11-16 검색 공백 1차 점검: 기존 연결은 정답이 아니며 전체 450문항 중 후보 없는 124문항은 추가 의미 검토가 필요하다. 자료에 기록된 일반 동작을 보완한 범위와 변경 전후 수치는 [점검 기록](tactics-retrieval-triage-2026-11-16.md)에 있다. 역할 합의는 기용 여부와 구분하며 미확인 조건을 기록된 사실로 올리지 않는다.


2026-11-16 단계 5 시범 실행: 450문항별 반환 2,019건(중복 포함, 고유 카드 136개)과 빈 결과 124건을 구조 대조하고 75개 상황군 대표를 AI가 의미감사했다. 별도의 고정 15문항 중 10건은 오프라인 기기 모델을 호출했고 5건은 설치 전 온라인 상태에서 후보 없음으로 호출하지 않았다. 실행 표본은 대표성을 검증하지 않았고, 추천 품질 통과·전문가·Android 실기기 검증은 남아 있다. 검색 관련성·조건 분류·후보 축소·지연을 우선 살핀다.
