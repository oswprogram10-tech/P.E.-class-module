## 질문 구성

[질문별 CSV](tactics-query-evaluation.csv)에 농구·배구·축구·티볼·피구 질문을 각각 90개씩, 총 450개 정리했다. 농구·배구·축구·피구는 종목별 15개 상황 유형과 유형별 6개 문장 표현으로 구성했다. 티볼은 v2에서 15개 유형마다 타구·주자·수비·경기 형식 조건을 달리한 6개 질문으로 고쳤다. 같은 유형의 문장 수를 독립 경기 상황 수나 실제 학생 질문 수로 간주하지 않는다. 모든 문장은 검색 결과 평가용 합성 질문이며 실제 경기 기록이나 모델 입력 학습자료가 아니다.

각 행에는 현재 카드 카탈로그에서 찾아볼 후보 ID, 후보 연결 상태, 추가 조사 출처 후보, 사람 검토 상태가 있다. 티볼 이외 종목은 한 유형의 여섯 표현에 같은 후보가 연결된다. 티볼 v2는 질문별 조건과 카드 요약을 대조해 후보를 유지·하향·제거했다. 이 연결은 **임시 후보**일 뿐 정답 라벨이 아니며, 교사·코치 또는 종목 분석자가 질문별로 실제 경기 맥락이 맞는지 확인해야 한다. 사람이 검토하기 전에는 검색 성능 수치로 사용하지 않는다.

[티볼 질문 전체와 개정 내역](tactics-teeball-questions.md), [질문별 비교 분류·확인할 규칙 CSV](tactics-teeball-question-context.csv)를 함께 사용한다. 공통 기술 42개와 규칙 확인이 필요한 질문 48개다. 조건부 질문의 규칙 대조는 모두 미완료이며, 임시 연결이 있어도 확정 연결이나 학생 제공 승인을 뜻하지 않는다. 기존 ID는 유지했으나 문장이 달라졌으므로 이전 연결 판정과 평가 수치를 재사용하지 않는다. 규칙 확인 전 보류와 근거 없는 발화·수비 조정 추정을 피하는 질문도 포함했다.

질문별 공백은 실제 경기 기록이 부족하다는 최종 판정이 아니라, 현재 사례 카드에서 직접 연결할 만한 확인된 후보를 찾지 못했다는 뜻이다. 부분 후보도 관련성을 보장하지 않는다. 티볼은 개정 후 질문 90개 중 68개에 기존 직접 사례 후보가 없어 야구 경기 사례를 비교 자료로 찾을 수 있다. 야구 자료는 티볼 사례로 표시하지 않고, 규칙 차이와 무관한 공통 기술 또는 티볼 규칙을 확인한 조건부 비교만 후보로 연결한다. 두 기준에 해당하지 않는 야구 장면은 티볼 검색 후보에서 제외한다. 별도로 야구 비교 장면 19개를 36개 질문에 50쌍의 조사 참고로 연결했다. Luna가 두 묶음에서 찾은 추가 11개 장면은 부모 에이전트가 원문을 다시 확인했다. 이번에는 후보가 없던 공통 기술 질문 13개에 부분 관련 참고를 추가했다. TE-03-02의 라이너성 타구는 기존 티볼 카드도 부분 관련으로 연결했다. 야구 비교 연결은 `research_lead_ids`와 [야구 비교 연결 CSV](tactics-teeball-baseball-links.csv)에 기록했고 위 표의 티볼 직접 후보·공백 집계에는 포함하지 않았다. TE-03-02에 붙인 기존 티볼 카드의 부분 관련 연결 1개는 직접 후보 집계에 반영했다. 관련성 제안은 8쌍이 핵심 기술 후보, 42쌍이 부분 관련 참고이며 모두 사람 검토 전이다. 기존 21쌍 중 3쌍을 하향했고 [질문별 공백 현황](tactics-teeball-coverage.md)을 별도로 작성했다. 공백 증가는 질문 개정 때 조건을 구체화하고 맞지 않는 임시 연결을 제거한 결과였으며, 이번에는 기존 티볼 카드의 부분 관련 연결 1개를 추가했다. TE-14-06은 기사 기반 관찰 범위 참고로만 연결했으므로 실제 영상·음성 검증은 보류다. [이번 13개 보강 결과](tactics-teeball-gapfill-2026-11-15.md)를 참조한다. 규칙 미확인 시 보류를 평가하는 질문에는 억지로 카드 후보를 붙이지 않는다.

## 남은 조사 공백

- **티볼:** 확인된 카드는 외야 위치·태그업 송구·득점 흐름에 치우쳐 있다. 주자 진루 판단, 포스 아웃 선택, 짧은 타구, 내야 위치 조정, 송구 뒤 백업과 수비 콜을 구체 장면으로 뒷받침할 자료가 부족하다. 야구의 타구 처리·수비 위치·중계·백업처럼 공통 기술인 장면과, 티볼 규칙을 확인한 뒤 비교할 수 있는 장면만 보강 후보로 조사한다. 이 기준에 맞지 않는 야구 장면은 티볼 검색 결과에 포함하지 않는다. 공식 규칙과 교육자료는 실제 경기 사례를 대신할 수 없다.
- **농구:** 리바운드 뒤 속공·패스·후속 주자의 부분 관련 장면을 연결했다. 선수의 실제 콜과 수비 전환 중 역할 분담·팀 전체 간격은 추가 근거가 필요하다.
- **배구:** 혼선 뒤 공을 살린 선수 연결과 실제 충돌 장면을 부분 관련으로 연결했다. 어떤 콜로 담당을 정했는지, 충돌의 원인이 무엇인지는 추가 근거가 필요하다.
- **축구:** 공식 UEFA 보고서의 코너킥·프리킥 마무리를 부분 관련으로 연결했다. 전체 조직 배치·마크·세트피스 이후 수비 재정렬·스로인은 추가 근거가 필요하다.
- **피구:** NDA·NCDA 실제 경기의 회피·재정비·코너 압박을 부분 관련으로 연결했다. 선수 간 간격 유지, 중앙 복귀, 자세·좌표와 다른 피구 형식의 규칙 적합성은 확인되지 않았다.

이번 야구 비교 19개 장면은 기사 본문 위치를 확인했다. 다음 단계는 관련성 제안을 검토하고 남은 출처 후보마다 경기 영상 또는 공식 기록에서 장면 위치를 확인하고, 질문별로 직접 관련·부분 관련·자료 없음 라벨을 사람이 정하는 것이다. 그 뒤 실제 공백에 해당하는 경기만 더 조사한다. 질문을 늘리는 것만으로 사례 데이터가 늘지는 않는다.
