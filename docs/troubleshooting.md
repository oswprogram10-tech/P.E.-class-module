# 문제 해결표 (초안)

상태: **G02 초안**. 현재 코드와 개발용 브라우저 검증을 기준으로 작성했으며, 실제 Android 기기·교실에서 검증한 기록이 아니다.

## 먼저 확인할 것

- 주소가 `https://`로 시작하는가. 카메라·PIN·오프라인 준비는 HTTPS에서만 동작한다.
- Chrome인가. Samsung Internet·다른 브라우저·iOS는 첫 출시 지원 대상이 아니다.
- 앱을 전면에 두고 화면이 꺼지지 않았는가.
- 최신 버전인가. 새 버전 배너가 있으면 앱을 완전히 닫았다 다시 열어 적용한다.

> **중요:** 문제를 해결하려고 Chrome의 **사이트 데이터 삭제**, **인터넷 사용 기록 전체 삭제**, **앱 데이터 삭제**를 하지 않는다. PIN과 이 태블릿에 저장한 클립이 모두 사라질 수 있다.

## 1. 카메라 권한을 거부했어요

1. Chrome 주소창 왼쪽의 자물쇠 또는 설정 아이콘을 눌러 **카메라** 권한이 **허용**인지 확인한다.
2. 허용으로 바꾼 뒤 앱 화면으로 돌아와 **카메라 시작**(또는 **촬영 다시 시작**)을 누른다.
3. Android 설정에서 Chrome의 카메라 권한이 꺼져 있지 않은지 확인한다.
4. 브라우저를 완전히 닫았다 다시 열어 같은 주소로 접속한다.
5. 그래도 권한 창이 나오지 않으면 주소가 HTTPS인지, 지원 대상 Chrome인지 확인한다.

권한을 허용하지 않으면 촬영할 수 없다. 사이트 데이터를 지우면 권한은 초기화되지만 PIN과 클립도 함께 사라지므로 시도하지 않는다.

## 2. 다른 앱이 카메라를 사용 중이에요

1. 화상 통화·카메라·스캔 앱 등 카메라를 쓰는 다른 앱을 모두 닫는다.
2. 앱으로 돌아와 **촬영 다시 시작**을 누른다.
3. 필요하면 태블릿을 재부팅한 뒤 다시 시도한다.
4. 다른 사용자 프로필이나 보안 앱이 카메라를 잠그고 있지 않은지 확인한다.

## 3. 카메라 연결 중에 멈춰요

1. Chrome의 카메라 권한 창이 다른 창 뒤에 숨어 있지 않은지 확인한다. 창이 보이면 **허용** 또는 **거부**를 선택해 요청을 끝낸다.
2. **카메라 연결 중…** 이 잠시 계속되는 것은 정상일 수 있으니 조금 기다린다.
3. 상태가 끝나 **촬영 다시 시작** 버튼이 나타나면 누른다. 연결 중에는 버튼이 비활성화되어 앱 안에서 요청을 취소할 수 없다.
4. 계속 **카메라 연결 중…** 에 머물면 Chrome을 완전히 닫았다 다시 열고, 같은 주소로 접속해 **카메라 시작**을 누른다.
5. 태블릿을 재부팅한 뒤 다시 시도한다.
6. 반복되면 기기 모델·Android 버전·Chrome 버전과 화면에 표시된 안내 문구를 기록해 담당자에게 전달한다. 사이트 데이터를 지우지 않는다.

## 4. 지연 영상이 계속 준비 중이에요

1. 화면의 **지연 영상 준비 중 · N초**가 줄어드는지 확인한다. 설정한 지연 시간만큼 영상이 쌓여야 재생이 시작된다.
2. 지연 시간이 60초처럼 길면 최대 1분 정도 기다린다.
3. 카메라가 실제로 촬영 중인지, **카메라 연결 중…** 에 머물러 있지 않은지 확인한다.
4. 앱을 전환하거나 화면을 잠갔다면 촬영이 중단된 것이다. **촬영 다시 시작**을 누르고 다시 기다린다.
5. 그래도 진행되지 않으면 **촬영 종료** 후 **카메라 시작**으로 다시 시작한다.
6. 지연 시간을 줄여도 같은 문제가 반복되면 기기·브라우저 정보를 기록한다.

## 5. 앱을 전환했더니 촬영이 멈췄어요

1. 앱으로 돌아온다.
2. **촬영 다시 시작**을 누른다.
3. 설정한 지연 시간만큼 버퍼가 다시 쌓일 때까지 기다린다.

중단 전 영상과 다시 시작한 영상은 이어 붙지 않는다. 중단 구간은 저장할 수 없다. 저장 중이었다면 저장이 취소됐을 수 있으므로, 선택 화면이 열려 있으면 같은 장면으로 다시 저장하고, 닫혔다면 장면을 다시 고른다.

## 6. 저장할 때 공간이 부족해요

1. 교사 메뉴 → **수업 설정** → **기기 저장 공간**에서 추정 용량을 확인한다.
2. 교사 메뉴 → **저장한 클립**에서 필요 없는 클립을 하나씩 삭제한다.
3. 태블릿 설정에서 다른 앱·사진·동영상이 차지하는 공간을 정리한다.
4. 브라우저의 다른 탭과 앱을 닫고 다시 저장한다.
5. 저장 공간이 충분해진 뒤 **이 장면 저장**을 다시 누른다.

저장에 실패해도 기존 클립은 유지된다. 공간을 만들려고 **사이트 데이터 삭제**를 하면 PIN과 모든 클립이 사라지므로 사용하지 않는다.

## 7. 교사 PIN을 잊었어요

PIN은 복구할 수 없다. PIN에서 파생한 키로 클립과 이름·번호를 암호화하므로, PIN 없이 기존 클립을 열 수 없다.

1. 교사 PIN 화면에서 **PIN 분실 · 기기 데이터 초기화**를 누른다.
2. 새 6자리 PIN을 두 번 입력한다.
3. 확인 문구로 정확히 **`모두 삭제`** 를 입력한다.
4. **모두 삭제하고 새 PIN 설정**을 누른다.

**이 초기화는 이 태블릿의 모든 로컬 클립과 학생 이름·번호를 삭제한다.** 삭제한 클립은 복구할 수 없다. 다른 기기의 데이터에는 영향을 주지 않는다. 이것은 일반적인 PIN 변경이 아니며, PIN만 바꾸면서 기존 클립을 유지하는 방법은 현재 없다. 초기화가 실패하면 기존 데이터와 PIN 설정이 유지되므로, 안내 문구를 확인한 뒤 다시 시도한다.

## 8. 클립이 사라졌거나 만료됐어요

1. 저장한 뒤 **7일**이 지났는지 확인한다. 저장 클립은 7일 만료 대상이다.
2. 앱을 완전히 닫았다 다시 열어 만료 정리를 실행한다.
3. 교사 메뉴 → **저장한 클립**에서 목록을 다시 확인한다.
4. 브라우저 데이터 삭제, 기기 초기화, 브라우저의 저장 공간 정리가 있었는지 확인한다.
5. 다른 태블릿에서 찾지 않는다. 클립은 그 태블릿에만 저장되며 동기화되지 않는다.

만료·삭제된 클립은 복구할 수 없다. 7일 만료는 앱이 닫혀 있는 동안 정확한 시각에 실행되지 않을 수 있지만, 앱을 다시 열면 만료된 클립을 정리한다. 만료 전이라도 브라우저 데이터 삭제·기기 초기화·저장 공간 정리로 더 일찍 사라질 수 있다.

## 9. 새 버전 안내가 계속 보여요

1. 수업 중이면 **나중에**를 눌러 배너만 닫는다. 현재 화면은 그대로 사용할 수 있다.
2. 수업이 끝난 뒤 앱을 **완전히 닫았다가 다시 연다.** 홈 버튼으로 뒤로 보내는 것이 아니라 최근 앱 목록에서 닫는다.
3. 다시 열어도 배너가 남아 있으면 잠시 뒤 한 번 더 완전히 닫았다 연다.
4. 업데이트 후 PIN과 클립 목록이 그대로인지 확인한다.

앱은 강제 새로고침이나 즉시 활성화를 하지 않는다. 업데이트를 서두르려고 사이트 데이터를 지우거나 캐시를 수동으로 삭제하지 않는다. PIN과 클립이 사라질 수 있다.

## 10. 그래도 해결되지 않을 때

다음을 기록해 담당자에게 전달한다. 학생 영상·이름·번호·PIN은 기록하지 않는다.

- 기기 모델, Android 버전, Chrome 버전
- 접속 주소(HTTPS 여부)
- 문제가 생긴 단계와 화면에 표시된 문구
- 앱을 완전히 닫았다 다시 열었는지, 기기를 재부팅했는지
- 같은 문제가 반복되는지
