# 장면 복습·비교·성찰 사용 안내

이 단계의 기능은 현재 기기 안에서 사용한다. 학생 영상·성찰을 다른 기기나 서버로 제출하지 않는다. 구현·검사 결과와 실기기 한계는 [S2 검증 기록](stage-S2-validation.md)을 따른다.

## 보고 있던 장면 고르기

**마음에 드는 장면 저장**을 누르면 실제로 지연 화면에 마지막 표시된 프레임을 끝 경계의 기본값으로 사용한다. 창을 연 뒤에는 선택 스냅샷을 고정하므로 실시간 버퍼가 움직여도 선택 장면이 바뀌지 않는다.

화면에 지연 장면이 아직 표시되지 않았거나 그 프레임이 이미 버퍼에서 사라졌으면 안내를 확인하고 다시 선택한다. 표시 장면 앞에 원하는 길이만큼 영상이 없으면 부족한 상태를 표시한다. 조용히 최신 장면으로 이동하지 않는다. 확보된 다른 시작·끝 프레임을 직접 고르거나 촬영 기록이 더 모인 뒤 다시 선택할 수 있다.

처음에는 길이와 끝나는 시점 조작으로 대략 고르고 **시작 프레임**, **끝 경계 프레임**으로 확보된 프레임 하나씩 조정한다. 경계를 움직이면 해당 장면을 멈춰 보여준다. 선택 구간 재생으로 반복 확인한다. 저장 범위는 시작 프레임부터 끝 경계 **직전까지**이며 끝 경계 프레임 자체는 포함하지 않는다.

유효한 저장 구간은 5~30초다. 프레임 시각이 일정하지 않아 실제 길이가 소수 초로 표시될 수 있다. 영상이 부족하거나 중간이 끊겼거나 길이 제한을 벗어나면 저장할 수 없다. 출력은 무음이고 선택 시각을 기준으로 10fps로 인코딩한다. 길이는 밀리초로 내림하므로 표시한 원 프레임 구간보다 1ms 미만 짧을 수 있다.

## 성찰 남기고 다시 보기

이름·번호와 함께 **잘된 점**, **다시 시도할 점**을 각각 300자 이내로 입력한다. 성찰은 영상과 연결된 암호화 메타데이터로 같은 기기에 보관하며 기존의 7일 만료·삭제 정책을 따른다. 이전에 저장한 성찰 없는 클립도 계속 열 수 있다. 장기 포트폴리오나 클라우드 제출 기능은 아니다.

교사 PIN으로 목록을 열고 **영상 보기**를 누른 뒤 재생 속도와 반복 재생을 조절한다. 속도를 바꿔도 원본 파일의 길이나 암호화 저장 데이터를 바꾸지 않는다. 목록을 닫거나 잠그면 재생과 접근을 정리한다.

**영상 파일 내보내기**는 교사 목록에서 명시적으로 실행한다. 확인창을 승인하면 무음 WebM 파일을 기기에 저장한다. 내보낸 파일은 앱의 암호화·PIN·7일 자동 삭제 보호 밖에 있는 **평문 영상 파일**이다. 기기 다운로드 폴더와 이후 공유 위치를 교사가 관리한다. 이름·번호·성찰을 파일명에 넣지 않으며 이 기능 자체가 서버 업로드를 수행하지 않는다.

교사 접근이 끝났거나 클립이 만료되면 내보낼 수 없다. 확인창을 열어 둔 동안 만료된 클립도 승인 후 다시 검사해 내보내지 않고 정리한다.

## 로컬 시범 영상 비교

기기의 영상 파일을 선택하고 지연 화면 위에 겹치거나 나란히 놓는다. 투명도·크기·가로/세로 위치·영상 시점을 조절하고 재생 또는 일시정지할 수 있다. 사용할 수 없는 파일은 안내 후 다른 파일로 바꾼다.

시범 영상은 메모리의 로컬 파일 URL로만 연다. 별도 서버나 외부 영상 주소를 사용하지 않고 앱 보관 클립으로 복사하지 않는다. **화면 비교 기능이며 저장 클립에 시범 영상을 합성하지 않는다.** 지우기·파일 교체 때 이전 URL을 해제하고, 앱이 가려지면 일시정지하며 페이지를 떠날 때 정리한다. 다시 실행하면 파일을 다시 선택한다.

## 1~300초 지연과 실제 버퍼 한계

교사 설정에서 1~300초를 고른다. 긴 지연은 그만큼 실제 촬영 시간이 먼저 지나야 하므로 초기에는 준비 중 안내를 확인한다. 설정을 줄이면 확보된 범위에서 다시 표시하고, 늘리면 필요한 만큼 더 기다린다.

실시간 버퍼는 최대 5분, 3,001프레임, JPEG 80MiB 중 먼저 도달한 한도로 제한된다. 선택 중인 스냅샷·영상 디코더·인코더와 브라우저 전체 메모리는 이 예산과 별도다. 복잡한 동작·고화질 영상은 같은 시간이라도 더 큰 공간이 필요할 수 있다.

정확히 300초 경계에서는 샘플 간격 때문에 저장 프레임의 시각 범위가 300초보다 조금 짧을 수 있다. 설정한 실제 촬영 시간이 경과하고 필요한 범위가 확보되었을 때만 최대 150ms의 경계 샘플 차이를 허용한다. 메모리 한도로 보관 범위가 크게 짧아졌다면 준비 완료로 표시하지 않고 지연 시간을 줄이라는 안내를 표시한다.

300초 설정을 제공하는 것이 모든 태블릿에서 300초 보관을 보장하지는 않는다. 개발용 가상 카메라의 실시간 측정과 실제 Android의 메모리·화질·발열 검증을 구분한다. 기기 확인 전에는 [기기 확인 절차](B03-B04-device-check.md)의 실기기 대기를 유지한다.
