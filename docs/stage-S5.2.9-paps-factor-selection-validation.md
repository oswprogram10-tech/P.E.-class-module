# S5.2.9 체력요소별 검사 선택 검증

기준일: 2026-11-07

## 공식 근거

교육부령 제354호 제7조제3항은 필수평가를 매 학년 초 체력요소별 검사항목 하나를 선택해 실시하도록 한다. 제8조제1항은 선택한 요소별 항목점수를 합쳐 신체능력 등급을 판정하도록 한다. 별지 제1호서식(학생건강기록부) 뒤쪽 제2쪽의 「항목별 평균기록 통계」는 다섯 요소와 종목을 다음처럼 묶는다.

| 체력요소 | 등록된 선택 계열 |
| --- | --- |
| 심폐지구력 | 왕복오래달리기, 오래달리기-걷기, 스텝검사 |
| 유연성 | 앉아 윗몸 앞으로 굽히기, 종합유연성 |
| 근력·근지구력 | 윗몸 말아 올리기, 악력, 팔굽혀펴기 |
| 순발력 | 50m 달리기, 제자리멀리뛰기 |
| 비만도 | BMI |

체지방률도 별지 서식에 나오지만 앱 입력·기준이 없어 선택지로 제공하지 않는다.

## 구현 범위

- 사용자가 선택한 대로 PAPS 설정은 학급·학년도별이며 학급 학년을 직접 지정해야 한다. 다섯 요소 각각 하나를 고르고 저장한다. 설정 본문·출처·수정 이력은 PIN 암호화 클래스 저장 상태에 포함된다.
- 선택할 학년·학년도 기준표에 존재하는 종목만 허용한다. 초3·초4 스텝검사, 초등 팔굽혀펴기, 초4 오래달리기-걷기 같은 비적용 선택은 거부한다.
- 오래달리기-걷기는 초5·초6에서 1,000m를 사용하고, 중·고에서는 남자 1,600m·여자 1,200m 기록으로 대응한다. 팔굽혀펴기 계열은 남자 기준에서 팔굽혀펴기, 여자 기준에서 무릎대고 팔굽혀펴기로 연결한다.
- 선택 기록은 입력 학년도부터 3개 학년도 뒤 3월 1일에 만료한다. 클래스 삭제·폐기와 오래된 저장 상태 복구를 처리한다.
- 저장된 선택만으로 종합점수를 계산하지 않는다. BMI의 정확한 점수 구간이 이 법령에 없어 BMI 항목점수·100점 총점·종합등급은 계속 미제공이다.
