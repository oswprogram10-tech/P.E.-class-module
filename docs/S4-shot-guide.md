# 농구 슛 동작 확인 안내

기준일: 2026-11-06. 이 기능은 S4.3의 실험적 READY→SHOOT 동작 감지다. 화면에 표시된 상태와 팔꿈치 각도는 카메라 관절 추정치로 만든 2D 움직임 신호이며 골 성공, 슛의 기술적 정확성, 점수나 성적을 뜻하지 않는다. 전체 S4 단계는 계속 진행 중이다. S4.1~S4.2의 설치·전신 확인은 [기초 안내](S4-foundation-guide.md), 개발 검사는 [S4.3 검증 기록](stage-S4-shot-validation.md)을 참고한다.

이후 S4.4의 선택적인 강조·효과음·임시 순간 이미지는 [피드백 안내](S4-feedback-guide.md)를 따른다. 아래의 미포함 범위는 S4.3 묶음 자체를 설명한다.

## 켜고 사용하기

1. 교사 PIN으로 설정을 연다. **농구 슛 동작 확인 사용**을 켜고, 촬영되는 사람 기준으로 슛하는 팔을 선택한다. 민감도는 `신중하게`, `기본`, `민감하게` 중 고른 뒤 **저장**한다. 초기값은 꺼짐·오른팔·기본이다.
2. 카메라를 켜고 **전신 확인 준비**를 완료한 뒤 **전신 확인 사용**을 켠다. 준비가 끝나지 않았거나 카메라가 멈추면 동작 감지도 진행하지 않는다.
3. 선택한 팔을 어깨 근처에서 굽혀 올려 READY가 표시되도록 잠시 유지한다. 이어 팔을 펴 위로 올리면 SHOOT 동작 신호가 표시될 수 있다. 상태 전환에는 연속 프레임과 유지 시간이 필요하며, 동작을 다시 감지하려면 팔을 내려 재준비한다.
4. 촬영 중인 사람의 팔이 화면에 잘 보이지 않거나 가려지면 전신 확인 안내를 따른다. 카메라 중단·화면 이탈·장면 선택·교사 설정 열기·학생/수업 맥락 변경·오래된 추론 결과는 준비 상태를 지운다. 상황을 바로잡고 새 READY부터 시작한다.

교사 설정은 PIN이 열린 동안만 편집할 수 있다. 저장에 실패하거나 값이 유효하지 않으면 기존 설정을 유지하고 오류 안내를 표시한다. 설정은 기존 앱 설정 저장소에 활성화 여부·팔·민감도만 보관되며 촬영 지연 설정은 보존된다. PIN 초기화 동작은 기존 삭제 규칙을 따르며 슛 설정을 기본값으로 되돌린다.

## 감지 기준과 한계

분석은 화면 비율을 반영한 어깨–팔꿈치–손목의 2D 각도, 귀·어깨 대비 손목 높이, 몸통 길이로 정규화한 위치를 사용한다. 현재 개발 임계값은 READY 팔꿈치 각도 130°/140°/150°, SHOOT 165°/160°/155°(각각 신중하게/기본/민감하게)이며 손목 높이 조건도 단계별로 달라진다. 각 단계는 최소 2개 프레임과 250ms 이상 유지되어야 한다. 기본 샘플링 간격은 약 333ms다. 이 수치는 개발용 휴리스틱이며 학생·기기·거리·촬영 방향에 맞춘 교육적 기준이나 정확도 보증이 아니다.

가림, 낮은 관절 신뢰도, 프레임 공백, 급격한 추적 기하 변화, 손 설정·수업 맥락 변경 및 카메라/화면 중단은 상태를 초기화한다. 기하 변화는 사람의 동일성을 인식하지 않는다. 거짓 감지와 놓침이 있을 수 있으므로 교사는 화면 상태를 참고 신호로만 사용한다.

원본 영상, 관절 좌표, 각도나 슛 시도 이력은 새로 저장·전송하지 않는다. 이 S4.3 기능은 음성 효과음, 자동 캡처, 플래시 알림, 영속 pose log, 학급 연결을 추가하지 않는다. 교사가 기존 촬영 흐름으로 따로 저장한 클립은 기존 보관 정책을 따른다. 합성 관절 시퀀스는 상태 전이 동작을 검증하는 데 쓰였고, 실제 fixture 한 장의 모델 추론은 모델과 각도 계산의 연결만 확인했다. 이 검사들은 실제 슛 감지 정확도를 입증하지 않는다.

실제 Android 기기·학교 환경, 40분 연속 사용, 전체 앱 메모리·발열, 여러 학생·조명·거리에서의 성능과 정확도는 확인 대기다. S4.4~S4.5 범위는 시작하지 않았다.
