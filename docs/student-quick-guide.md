# 학생용 한 장 안내

**PE Loop — 내 움직임을 보고, 한 번 더 도전해요**

## 이렇게 해요

1. **태블릿에서 2~3걸음 떨어져요.** 머리부터 발끝까지 화면에 보이게 서요.
2. **내 차례가 되면 움직여요.** 잠시 뒤에 내 모습이 화면에 다시 나와요.
3. **천천히 지연 영상을 봐요.** 어디를 고칠지 생각해요.
4. **선생님이 저장해도 된다고 하면** **마음에 드는 장면 저장**을 눌러요.
5. **장면 끝나는 시점**과 **저장할 길이(5~30초)** 를 골라요.
6. **내 이름과 번호**를 쓰고 **이 장면 저장**을 눌러요.
7. **저장이 끝날 때까지 기다려요.** 화면을 바꾸거나 태블릿을 잠그지 않아요.

## 꼭 기억해요

- 영상은 **소리가 나지 않아요.**
- 영상은 **이 태블릿에만** 저장돼요. 인터넷으로 보내지 않아요.
- 저장한 영상은 **7일이 지나면 지워져요.** 그 전에 없어질 수도 있어요.
- 잘 모르겠으면 **선생님께 물어봐요.**
