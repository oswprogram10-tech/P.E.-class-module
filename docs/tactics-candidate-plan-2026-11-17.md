# 후보 계획 토큰 및 구조 대조

450문항은 75개 상황군의 표현 여섯 개씩이다. 입력은 질문 문장·종목·overall뿐이며, 질문 ID와 기존 연결 참고목록은 결과 대조에만 사용했다. 참고목록은 정답이 아니며 이 결과는 정확도가 아니다. 기기 모델은 호출하지 않았다.

기존 프롬프트 후보 0/1/2개: 140 / 123 / 187문항. 2→1 절삭: 74문항. 단일 후보 초과: 0문항.
새 계획 후보 수별 문항: {"0":140,"1":101,"2":170,"3":38,"4":1,"5":0,"6":0,"7":0,"8":0}. 계획 오류: 0, 후보 생략: 250, 구조 검사 위반: 0문항.
기존 연결과 하나 이상 겹친 문항: 예산 적용 전 상위 2개 192, 기존 실제 제시 181, 새 계획 실제 제시 181 (새로 겹침 3, 겹침 소실 3); 참고목록 없는 문항 34.

토큰 수는 실제 공유 Qwen 토크나이저에 ChatML 예약 4개를 더해 계산했다. 구조 검사는 계획 프롬프트와 projection 일치, 토큰 예산, 누락 수, 원본 필드·근거 단위 보존을 확인한다. 문장 의미의 관련성, 규칙 적용, 모델 선택 품질은 평가하지 않는다. 전체 결과와 실행 전후 SHA-256은 JSON에 기록했다.

추가 대조: 기존 실제 프롬프트와 비교해 새 계획의 제시 후보 수가 증가한 문항은 68개, 감소한 문항은 7개다. 기존에 실제 제시한 ID 일부가 새 계획에서 빠진 문항은 41개이며, 기존 검색 3위 이하 후보가 새로 제시된 문항은 101개다. 따라서 후보 수 증가가 기존 상위 후보 보존이나 관련성 개선을 보장하지 않는다. 티볼의 여섯 표현은 타구 위치·수비 배치·주자·경기 형식 등 조건도 달라질 수 있어 단순한 동의어 재표현으로 간주하지 않는다. 티볼과 야구의 공통 기술을 비교할 때도 학교 경기의 규칙과 조건 차이는 별도 확인이 필요하다. 이 추가 설명은 생성된 수치 기록에 실행 후 덧붙였다.
