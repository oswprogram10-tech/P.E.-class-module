# 기기 AI 응답 준비와 메모리

2026-11-17 구현: 같은 탭에서 성공한 기기 AI 실행 뒤 약 2GB 모델을 준비한 메모리를 잠시 보유하여 다음 요청에서 준비 과정을 재사용한다. 매 요청의 사례 검색과 모델 선택은 다시 실행한다. 모델은 유휴 30초 후 해제하며, 학생 모둠 초기화·패널 닫기, 교사 잠금·학급 전환, 화면 숨김이나 페이지 종료 때도 해제한다. 다른 탭은 메모리가 유지되는 동안 모델 작업이 사용 중임을 표시한다.

학생 화면과 교사 기기 설정의 **AI 메모리 비우기**는 실행 중인 작업을 중단하고 메모리를 해제한다. 다운로드한 모델 파일은 유지된다. 저장 공간의 모델 파일을 지우려면 교사 설정의 **기기에서 모델 삭제**를 별도로 사용한다. 다음 AI 실행은 모델을 다시 준비해야 한다.

후보 폭, 512 토큰 입력 한도, 출력 선택 최대 두 개와 개인정보 확인은 그대로다. 원문과 모델이 보는 제한된 근거를 구분하고 출처와 빠진 조건을 확인한다. 지정한 로컬 서버 방식은 이 기기 모델 메모리 재사용과 별개다.
