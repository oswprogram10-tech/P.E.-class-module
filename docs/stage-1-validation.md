# S1 출시 준비의 구현·검증 기록

검증일: 2026-11-05. 환경: Linux, Node v24.22.1, Chromium 155.0.8059.79, Playwright, 가상 카메라, 로컬 HTTP loopback 및 FFmpeg/ffprobe. 실제 Android·외부 HTTPS 배포·현장 교사 검증은 수행하지 않았다.

## 단계 판정

**S1 전체는 부분 완료다.** 로컬 코드·문서·개발용 자동 검증과 실제 기기·수업·배포 조건을 구분한다. [세션 목표](session-goals.md)의 순서와 완료 기준을 유지하며 S2에는 착수하지 않았다.

| --- | --- | --- |

## 업데이트와 캐시 정책

`sw.js`는 `pe-loop-shell-v6`의 셸 전체를 설치 때 준비하고, 활성 버전 자신의 캐시만 제공한다. 홈과 `index.html`의 query navigation도 같은 캐시 HTML을 사용한다. 필수 파일이 없을 때 다른 버전의 네트워크 파일을 섞지 않는다.

설치에서 `skipWaiting()`을 호출하지 않고 활성화에서 `clients.claim()`도 호출하지 않는다. 새 버전은 이전 버전이 제어하는 앱 창이 모두 종료될 때 자연 활성화한다. **업데이트 준비**는 종료·재실행 안내이며 클릭 즉시 갱신하는 버튼이 아니다. 다른 탭의 촬영·저장 상태를 한 탭이 강제로 바꾸지 않는다. 대기 워커에 직접 적용 메시지가 와도 강제 활성화하지 않는다.

활성화 시에는 구 `pe-loop-shell-` 앱 캐시만 정리한다. IndexedDB의 PIN·암호화 클립과 다른 이름의 캐시는 보존한다. 셸 파일이 바뀌면 캐시 버전을 올리고 같은 빌드의 파일을 원자적으로 배포해야 한다.

기존 v5의 네트워크 우선 HTML·캐시 우선 스크립트 정책은 새 코드가 실행되기 전의 첫 전환에 영향을 줄 수 있다. 새 정책을 쓰는 두 버전 간 검사와 기존 v5의 안전성을 동일하게 주장하지 않는다. 첫 전환은 수업을 마친 뒤 모든 앱 창 종료·재실행 절차를 따른다.

로컬 서버는 기본 sandbox에서 `listen EPERM`으로 막혔다. 필요한 검사만 최소 권한의 실행으로 진행했다. Node 기본 출력의 파일 단위 5개와 TAP의 개별 테스트 13개를 구분한다.

기존 Node 13개와 브라우저 7개 스크립트, 신규 PWA·화면 2개 스크립트의 통과를 확인했다. Terra가 제품과 복잡한 PWA 검사를 구현했고 Sol이 통합 검토·회귀·화면 검사를 수행했다. Luna는 제품·문서를 별도로 읽고 최종 PWA 검사를 직접 실행해 종료 코드 0을 확인했다. 마지막 독립 실행에는 오프라인 재실행 뒤 준비 표시가 `ready`인지 확인하는 검사도 포함했다.

기존 clips 검사는 `seeked` 직후 이전 표시 프레임을 읽어 색상 검사에 실패했다. 변경 없는 HEAD 기준본에서도 동일하게 재현했고, 2초 시점이 첫 프레임 픽셀을 반환하는 것을 확인했다. 다음 `requestVideoFrameCallback`까지 기다리도록 검사 동기화를 수정했다. 기대 장면·색상 오차·FFmpeg 확인은 유지했으며 수정 후 통과했다.

모의 준비 시간은 최초 설치·권한·PIN 생성을 마친 상태에서 PIN 입력 → 지연 설정 → 창 닫기 → 가상 촬영 첫 프레임까지 460ms였다. 자동화 입력의 결과이며 실제 교사의 준비 시간이나 Android 성능 결과가 아니다. 낮은 입력 화면 검사는 viewport를 줄인 것으로 Android 키보드 검증을 대신하지 않는다.

## 미확인과 운영 한계

- 오프라인 준비 완료는 셸 캐시 파일이 있다는 뜻이다. 카메라 권한·저장 공간·지원 인코더나 파일 내용의 체크섬 검증까지 보장하지 않는다.
- 필수 캐시 파일이 손실되면 동일 코드의 워커 재검사만으로 복구되지 않을 수 있다. 완전한 파일을 담은 새 캐시 버전을 설치하고 모든 창을 종료·재실행한다. 사이트 전체 데이터 삭제는 클립·PIN까지 지울 수 있으므로 복구 수단으로 안내하지 않는다.
- 실제 A9+의 RAM·Android·Chrome, 저사양 기기, 40분 촬영·발열·메모리·배터리·화질, 실제 카메라 권한·잠금·재시작은 외부 조건 대기다. 합성 40분 검사로 대체하지 않는다.
- 외부 HTTPS 설치 주소·접근, 실제 배포·버전 복귀, 학교 수업 파일럿은 미실행이다. 이번 작업에서 commit/push·외부 배포·클라우드 설정 변경은 하지 않았다.
