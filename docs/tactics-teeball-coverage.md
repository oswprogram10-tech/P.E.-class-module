# 티볼 질문별 자료 공백 현황

갱신일: **2026-11-15**

티볼 질문 v2의 직접 카드와 야구 비교 후보를 질문 ID 기준으로 합쳐 조사 우선순위를 표시했다. 중복 연결을 질문 수로 세지 않으며 후보 개수는 검색 성능·교사 승인·실제 효과를 뜻하지 않는다.

| 현재 조사 상태 | 질문 수 |
| --- | ---: |
| 공통 기술: 핵심 비교 후보 있음·미검토 | 6 |
| 공통 기술: 부분 관련 후보만 있음·미검토 | 35 |
| 공통 기술: 직접·비교 후보 모두 없음 | 0 |
| 공통 기술: 관찰 범위 참고만 있음·영상 검증 보류 | 1 |
| 조건부 비교: 규칙 대조 미완료 | 48 |

핵심 비교 후보는 요청한 기술의 근거가 있다는 AI 보조 판정이다. 질문의 모든 조건이 일치하거나 추천 전술이 검증되었다는 뜻은 아니다. 부분 관련 후보는 빠진 조건을 명시하고 비교 한계를 설명하는 데만 쓴다. 규칙 대조가 필요한 질문은 직접 카드가 연결되어 있어도 규칙 확인 상태를 별도로 유지한다. 모든 사람 관련성 검토는 미완료다. TE-14-06은 기사로 확인한 움직임을 참고해 발화를 추정하지 않는 범위만 기록했다. 실제 영상·음성 관찰은 보류 상태이며 경기 장면을 직접 검증한 질문으로 세지 않는다.

전체 90개 질문의 근거 상태·확인할 규칙은 [질문별 현황 CSV](tactics-teeball-coverage.csv)에 있다. [기존 연결 재검토](tactics-teeball-link-review.md)와 [추가 조사](tactics-teeball-baseball-research.md)를 함께 참조한다.
