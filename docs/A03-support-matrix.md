# A03 — 지원 기준과 기기 확인표

상태: 기준 기기 선정 및 확인 절차 작성 완료, **실제 기기 구성 확인 대기**.

사용자 답변: 갤럭시 탭 A9+를 기준으로 하되 실기기 확인은 당분간 어렵다. 따라서 Android·Chrome·RAM 버전이나 정식 최소 지원 기기를 추정해 완료 처리하지 않는다.

## 지원 정책과 현재 근거

| 구분 | 대상·기준 | 상태 |
| --- | --- | --- |
| 기준 태블릿 | Samsung Galaxy Tab A9+ | 사용자 확정 |
| 기준 RAM·모델 세부 번호 | 미확인 | 실기기 확보 후 기록 |
| 기준 Android 버전 | 미확인 | 설정 화면에서 실제 버전 확인 필요 |
| 기준 Chrome 버전 | 검증 당시의 기기 Chrome 안정 버전과 전체 버전 번호 기록 | 실기기 대기 |
| 최소 지원 하드웨어 | 기준 기기의 실제 측정 후 결정 | 미확정. A9+ 이하 기기 지원을 약속하지 않음 |
| 최소 지원 Android·Chrome | 필수 API와 실제 검증 결과에 따라 결정 | 미확정. OS·브라우저 이름만으로 지원 판정하지 않음 |
| 사용 방식 | Android Chrome 탭 및 홈 화면 설치 PWA | 사용자 확정, Android 실측 대기 |
| 개발용 브라우저 | Linux Chromium 155.0.8059.79, Debian GNU/Linux 13 | 도구 버전 명령으로 확인 |
| 개발용 자동화 화면 | 1280×900 CSS px | A9+ 화면 실측이나 성능 에뮬레이션을 뜻하지 않음 |
| 기타 브라우저 | Samsung Internet·다른 Chromium 브라우저·iOS·WebView | 첫 출시 지원 확정 대상 아님 |

## 필수 기능 확인표

| 기능 | 필요한 능력 | 실패 시 처리 |
| --- | --- | --- |
| 촬영 | HTTPS 보안 컨텍스트, MediaDevices.getUserMedia, 실제 작동하는 카메라 | 촬영 불가 이유와 권한·기기 확인 안내 |
| 프레임 처리 | Canvas 2D, toBlob, createImageBitmap | 지연 영상 기능 사용 불가 안내 |
| 영상 생성 | VideoEncoder·VideoFrame(WebCodecs), VP8 인코딩 지원, 재생 가능한 무음 WebM | 파일을 생성했다고 표시하지 않고 지원 브라우저 안내 |
| 암호화 | Web Crypto, PBKDF2/SHA-256, AES-GCM, 보안 난수 | PIN·저장 기능을 활성화하지 않음 |
| 로컬 보관 | IndexedDB 및 실제 쓰기 가능한 저장 공간 | 기존 파일을 유지하며 저장 실패·공간 부족 안내 |
| 오프라인 실행 | 서비스 워커·Cache Storage·정상적으로 완료한 첫 설치 | 오프라인 준비 여부 확인 전 사용 가능하다고 보장하지 않음 |
| 화면 꺼짐 방지 | Screen Wake Lock | 선택 기능. 거부되면 화면 잠금 시 중단·복귀 흐름 적용 |

API 이름이 존재하는 것과 실제 기기에서 원활하게 작동하는 것은 다르다. 카메라 시작·WebM 생성·복호화 재생까지 실행한 결과를 별도로 남긴다.

## 실기기 확보 시 기록할 항목

| 항목 | 기록 |
| --- | --- |
| 확인 날짜·담당자 | 미확인 |
| 모델 세부 번호·RAM | 미확인 |
| Android·One UI 버전 | 미확인 |
| Chrome 전체 버전 | 미확인 |
| 일반 탭 / 설치 PWA | 각각 결과 기록 필요 |
| 앱 배포 버전·HTTPS 주소 | 미확인 |
| 배터리 시작·종료, 충전 여부 | 미측정 |
| 촬영 방향·카메라·실내 조도 | 미측정 |
| 40분 연속 촬영·버퍼·메모리 결과 | 미측정 |
| 잠금·앱 전환·권한 철회·재시작 | 미측정 |

실기기 확인이 가능해지기 전까지 추가로 같은 정보를 요청하지 않는다. A03 완료 조건은 모델 선정뿐 아니라 실제 버전·최소 지원 기준·검증할 브라우저를 기록하는 것이므로 대기 상태를 유지한다.

실기기 절차는 [B03·B04 확인 절차](B03-B04-device-check.md)를 따른다.
