# 5단계 검색·답변 평가 통합 기록

2026-11-16 기준. 계획한 시범 평가는 실행했으나 추천 품질 통과 판정은 보류한다. 450개 질문은 75개 상황군에 문항 6개씩이며, 티볼 문항은 규칙과 경기 조건도 달라진다. 독립된 450개 실제 경기 사례가 아니다. 기존 후보 연결은 참고목록이지 검증된 정답이 아니다. 아래 세 평가는 서로 다른 범위를 측정하며 수치를 합쳐 정확도로 해석하지 않는다.

| 평가 | 범위와 현재 상태 |
| --- | --- |
| 자동 구조 계약 | 450문항 검색 완료: 질문별 검색 반환 2,019건(중복 포함, 고유 카드 136개), 후보 없음 124문항. 실제 공유 검색 참조에서 search 카드로 지정 필드를 전달하는 비교 오류 0개. 합성 ID 선택 검증에서 중복·미제공 ID·추가 필드·2개 초과 등 거부 확인. 모델 선택 품질과 원자료→검색 참조 또는 UI 전체의 보존을 증명하지 않는다. [상세](tactics-stage5-evidence-contract.md) |
| 독립 AI 의미감사 | 상황군별 첫 문항 75개와 상위 두 후보, 가능한 경우 미검색 기존 제안 하나를 카탈로그의 관찰·맥락·범위로 검토했다. 잠정 분류는 부분 관련 38, 핵심 근거 약함 14, 후보 없음 23. 전체 후보나 외부 원문 검증이 아니며 사람·전문가 검토가 아니다. [질문별 근거와 한계](tactics-stage5-evidence-semantic.md) |
| 실제 모델 표본 | 사전에 정한 15문항 중 후보 있는 10건은 오프라인 Chromium에서 실제 3B 모델 생성, 후보 없는 5건은 설치 전 온라인 상태에서 모델 호출 생략을 확인했다. 10건 모두 유효 ID를 반환했으며 전체 호출 지연은 약 136~266초였다. 표본은 모집단 대표성을 검증하지 않았고, 450회 모델 생성이나 Android 실기기 검증이 아니다. 기존 참고목록과 겹친 256문항 중 204문항은 예산 적용 전 상위 두 후보에도 겹치는 ID가 있었고 52문항은 3위 이하에만 있었다. 참고 연결은 정답이 아니므로 이는 품질 누락률이 아니다. 다만 기기 모델은 상위 두 후보만 받고 512토큰 한도 때문에 하나로 줄어들 수도 있어, 검색 목록 전체와 모델이 고를 수 있는 목록은 다르다. 실제 생성 10건 중 3건은 512토큰 한도로 상위 2개에서 1개로 축소됐다.

검토 우선순위는 다음과 같다.

1. **질문 조건과 후보 관련성:** TE-08-01은 땅볼의 포스아웃 선택을 묻지만 상위 후보는 중계 송구와 뜬공 태그업이다. TE-12-01도 같은 규칙에서의 내야 송구 선택을 확인하지 못한다. 학교 규칙 일치를 추정하지 말고 장면과 규칙의 근거를 다시 확인해야 한다. BA-10-01은 포스트 도움 대응을 묻지만 상위 사례는 그 조건이 약하고, 관련된 기존 제안은 검색되지 않았다.
2. **검색되지 않은 비교 후보:** TE-01-01의 티볼 외야 전진·후진 사례, VO-09-01의 프리볼 사례 등은 재검토할 만하다. 기존 제안이 있다는 사실만으로 반드시 검색되어야 한다고 판정하지 않는다. 실패·반대 대응도 질문 조건이 맞으면 유용한 비교 사례다.
3. **부분 관련과 범위:** 야구 장면은 원종목을 유지하고 티볼과의 공통 동작으로만 비교하며 학교 규칙을 미확인으로 둔다. TE-14-06은 후보가 없고 TBX-01 연결은 무음 영상 장면 근거가 아닌 관찰 한계 참고다. 특정 발화를 추측하지 않는다.
4. **기기 모델 선택과 지연:** 10건 중 9건은 노출된 후보를 모두 선택했고 TE-02-01은 2개 중 태그업 송구와 가까운 티볼 사례만 골랐다. 유효 ID는 의미상 적절한 선택의 증거가 아니다. AI 검토에서는 전면 압박 조건이 빠진 사례를 direct로 표시하거나, 픽앤팝을 screen 미충족으로 표시하는 등 조건 태그 재검토가 필요했다. 약 136~266초의 표본 지연도 개선 대상이다.

현재 자료만으로 추가 학습이 즉시 필요하다고 판단할 근거는 없다. 우선 후보의 관련성과 누락 조건, 상위 후보 제한의 영향을 검토하고 실제 모델 표본에서 드러난 선택과 지연을 개선한다. 이후에도 문제가 모델의 요청 이해나 선택에서 발생한다고 확인되면 별도로 학습 필요성을 평가한다.

시범 자료의 수용은 전문가 검토나 자료 이용 권리 확인을 뜻하지 않는다. 학교 수업·Android 실기기·오프라인 배포 및 업데이트 검증은 별도로 남아 있다.

개발 확인: 관련 단위·CLI 검사 32개가 통과했다. 실제 모델 표본의 호출 지연 중앙값은 약 195초이며, 이 실행 환경의 수치다.
