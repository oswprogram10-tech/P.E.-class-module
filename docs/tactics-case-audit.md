2. **배구 연구 3개는 경기 장면이 아님:** 배구 4·5·16번은 여러 경기의 스파이크, 사이드아웃, 세팅 구역을 집계한 연구다. C 분류로 두고, 장면 카탈로그에서 빼서 연구 배경/검색 분류 근거로 보관한다. 배구 4번의 PubMed 페이지는 직접 요청에서 203을 반환했으나 검색 색인에서 PMID 40917620, PMCID PMC12411457, DOI 10.3389/fspor.2025.1630870가 확인됐다. [PMC 전문](https://pmc.ncbi.nlm.nih.gov/articles/PMC12411457/)을 배경 자료의 출처로 사용할 수 있다.
3. **축구 역사·팀 모델 2개는 단일 장면이 아님:** 축구 26·27번은 AC Milan과 Barcelona의 여러 시즌 팀 스타일 설명이다. C 분류로 두고 역사·용어 참고 자료로 분리한다. Ajax-Inter 1972와 Inter-Real Madrid 1964 관련 카드도 실제 경기 결과는 확인 가능하지만, 출처가 특정 플레이를 보여 주지 않아 B로 분류했다.

## 운영상 중요한 차이

카드 137개는 현재 전부 `draft`다. [`server/tactics-llm.js`](../server/tactics-llm.js)는 오프라인 용어 검색으로 종목·요청과 가까운 후보 8개까지만 Ollama에 보내며, 출처 대조 `verified`, A/B 등급, `aiUseBlocked`가 아닌 카드만 후보로 삼는다. 배구 33번의 부분 확인과 C 등급 5개, AI 제한 배구 42·43번은 제외되어 현재 후보 풀은 129개다. 다만 `reviewStatus` 교사 승인 게이트는 아직 없고 후보 129개도 모두 `draft`이며 앱 재사용 권리가 확인되지 않았다. 검색 구현은 가중치 학습이 아니며, 권리·교사 검토가 끝나기 전 카드를 승인 자료로 표시하지 않는다.
