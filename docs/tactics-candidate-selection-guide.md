# 기기 AI 경기 사례 선택 안내

학생 또는 교사는 상황을 적고 먼저 자료 검색 결과의 출처, 경기 조건과 한계를 확인할 수 있다. 기기 AI 선택을 실행하면 검색된 후보 중 모델 입력에 들어간 범위에서 비교 사례를 고른다. AI가 빈 선택을 반환해도 검색 결과 카드는 유지된다. 이는 자료가 없다는 뜻이 아니다. 오류나 취소 시에도 기존 검색 결과가 남는다.

AI 실행과 선택 성공은 별개다. 화면에 검색 후보 수와 모델에 보여 준 후보 수를 표시한다. 입력 크기 제한 때문에 일부 후보와 원문 전체, 비교 범위·한계의 일부가 모델 입력에서 빠질 수 있다. 화면의 전체 카드와 출처를 직접 확인하고, 교사·코치 검토 전 자료와 야구 원본을 티볼에 부분 비교하는 조건을 고려한다. 사례는 정답이나 실행 지시가 아니다.

브라우저 검사는 모의 응답으로 성공·빈 선택과 검토 범위 표시를 확인하며 모델 품질을 평가하지 않는다. 이번 후보 구성의 실제 3B 모델 두 문항을 측정했다. 이전 날짜의 모델 측정 기록과 그 소스 SHA는 측정 당시 구성의 기록이며 현재 수정된 수동 검사 도구의 SHA가 아니다.

후보 구성은 입력 한도에 맞게 일치한 비교 범위 하나를 원문 그대로 발췌하며, 앞선 후보가 길어지면 뒤의 더 짧은 후보가 대신 포함될 수 있다. 450개 요청의 구성 평가에서 모델에 제시된 후보 수가 0/1/2/3/4개인 요청은 각각 140/101/170/38/1개였다. 3개 이상은 39개 요청이고 512 토큰 예산 오류는 0건이었다. 이전 참고 목록과의 겹침은 181건에서 181건이며 획득과 소실이 각각 3건이다. 후보 수는 68문항에서 늘고 7문항에서 줄었다. 이는 입력 구성의 관찰이지 선택 정확도 평가는 아니다. 학생·교사 화면의 모의 브라우저 검사에서 빈 선택 시 검색 카드 유지와 검토 범위 표시를 확인했다. 실제 3B 모델은 두 문항에서 각각 후보 3개를 입력받아 2개를 선택했다. 두 결과는 부분 기술만 관련되고 요청의 핵심 조건인 주자 되돌아감과 주자보다 빠른 베이스 송구를 원문에서 확인하지 못했다. 입력 투영과 출력 문법 통과는 선택 정확도 통과를 뜻하지 않는다. [실측 보고서](tactics-candidate-plan-model-2026-11-17.md)와 [결과 JSON](tactics-candidate-plan-model-2026-11-17.json)을 참고한다. 이 환경에서 각각 469,107ms와 462,615ms가 걸려 속도 개선이 남아 있다. 이전 날의 다른 질문 측정과 단순 비교하지 않는다.

모델 입력에는 기존 카드의 관찰 문장 전문과 시범 자료의 제한된 비교 범위만 담는다. 결과 화면에는 검색 카드의 전체 원문과 범위·한계를 유지한다. 긴 요청이나 카드 한 개도 512 토큰 입력 예산에 들어가지 않으면 AI 오류를 표시하며 기존 검색 자료는 계속 사용할 수 있다. 선택은 최대 두 사례로 제한되며, 선택 결과의 관련성과 조건은 직접 확인해야 한다. 실제 추론은 최종 교사 빈 검색 안내 수정 전의 동일한 모델·검색 실행 코드로 측정했다. 이후 화면 안내와 서비스 워커 캐시 버전만 변경했다.
