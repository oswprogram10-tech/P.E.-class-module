# S5.2 PAPS 기준 출처와 적용 범위

검토일: 2026-11-06 (한국 시간)

## 확인한 공식 자료

사용자가 제공한 「학교건강검사규칙(교육부령)(제00354호)(20250310).pdf」를 기준 자료로 확인했다. 규칙은 교육부령 제354호로 2025년 3월 10일 일부개정·시행되었고, 별표 4의 종목별 등급표도 2025년 3월 10일 개정 표기다. PDF 원문 SHA-256은 `c370d499772929837d35fed32b8d4d8fca195e6e07970b5a8e25efa344bc01e8`이다.

- 별표 3, PDF 16쪽: 검사 방법과 기록 단위. 앉아 윗몸 앞으로 굽히기와 제자리멀리뛰기는 0.1cm, 악력은 0.1kg 단위까지 기록한다. 이 근거로 제자리멀리뛰기 수기 입력 정밀도를 1자리로 맞췄다.
- 별표 4, PDF 17~18쪽: 남녀별 초3~고3 행과 종목별 5~1등급 경계.
- 별표 5·6, PDF 20쪽: 필수 평가 점수와 신체능력 종합등급 체계.
- 법령 링크: [국가법령정보센터 학교건강검사규칙](https://www.law.go.kr/법령/학교건강검사규칙)

별표 4의 원문 표에서 앱이 이미 기록하는 왕복오래달리기, 앉아 윗몸 앞으로 굽히기, 윗몸말아올리기, 악력, 제자리멀리뛰기만 옮겼다. 남녀 2개 대상 구분 × 10개 학년군 × 5개 종목, 총 100개 적용 행을 등록했다. 시행일 전 학년도나 다음 개정 여부를 추정하지 않으며 현재 등록 범위는 2026학년도다.

## 계산 범위와 제한

`paps-criteria-data.js`는 별표 4 숫자 경계와 원문 식별 정보를 보관한다. `paps-criteria.js`는 학년도·학년군·종목·단위·대상 구분이 모두 일치하고 대상 구분을 명시 확인했을 때 개별 종목의 별표 4 등급을 찾는다. 교사 입력 화면은 학년과 남자/여자 평가표를 자동 추정하지 않고 직접 선택하게 한다. 범위 양 끝은 포함한다. 별표 4 각주에 따라 최저 구간 아래는 5등급, 최고 구간 위는 1등급으로 표시한다. 경계 사이에 값이 비면 결과를 만들지 않는다.

교사가 기준 학년과 평가표 구분을 확인하면 화면에 종목별 5~1등급 미리보기를 표시하고, 값과 함께 선택한 범위·기준 버전을 PIN 암호화 로컬 기록에 보존한다. 학생을 바꾸면 이 선택을 초기화한다. 이 범위는 측정 원자료와 별도이며 점수, 5개 체력요소 종합점수, 종합등급, 백분위, 건강 진단, 운동 처방, NEIS 출력은 생성하지 않는다. 규칙에서 백분위 산식을 확인할 수 없어 `unavailable / not-defined-in-regulation`으로 고정했다. 별표 5는 다섯 체력요소 점수와 BMI를 함께 다루지만 현재 입력 다섯 종목에는 같은 근력·근지구력 요소의 두 종목이 있고 BMI 입력은 없다. 그러므로 현재 자료만으로 전체 PAPS 점수를 만들지 않는다.

표에 있는 오래달리기-걷기, 스텝검사, 종합유연성, 팔굽혀펴기, 50m 달리기는 현재 S5.1 입력 항목에 없어 등록하지 않았다. BMI 표도 별도 신체 분류이므로 BMI 계산·비만 판정 기능에 사용하지 않는다. 초3은 규칙 제7조에 따른 선택 평가 대상이며, 표에 기준이 있다는 사실을 의무 측정으로 표시하지 않는다.

## 검증 근거

PDF 표 셀을 읽어 정적 데이터로 옮겼고, 남녀별 표 페이지와 종목 열을 확인했다. 카탈로그 생성 시 100개 행 모두에 대해 5개 등급, 수치 정밀도, 겹침·누락 경계를 검증한다. 회귀 테스트는 남녀·10개 학년군·5개 종목의 각 등급 양 끝 값을 모두 분류하고, 범위 밖 처리·대상 확인·학년도·단위 불일치·원문 해시·백분위 미제공 상태를 검사한다. 이미지로 읽기 어려운 표를 원문 PDF에서 대조할 수 있게 되어 기존 사용자 제공 표 이미지와도 대표 경계값을 확인했다.

적용 기준은 문서 개정에 따라 바뀔 수 있다. 2026학년도 이후 기준을 쓰기 전에는 국가법령정보센터의 최신 별표를 다시 확인하고 새 기준 버전을 등록해야 한다. 2025학년도 초의 개정 전·후 적용 구간은 별도 학년도/측정일 계약이 없어 이 카탈로그 범위에서 제외한다.
