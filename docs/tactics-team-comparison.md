# 모둠의 경기 사례 비교와 교사 검토

학생 화면에서 종목과 현재 상황·막힌 점·비교하고 싶은 점을 입력하고 **자료에서 사례 찾기**를 누른다. 이름, 학번, 학교명, 연락처는 입력하지 않는다. 모델을 설치하지 않아도 검색할 수 있다. AI 선택은 별도 선택이며 설치된 모델이 필요하고 오래 걸릴 수 있다.

결과에서 최대 두 사례를 선택하면 두 카드가 나란히 표시되고 작은 화면에서는 세로로 놓인다. 표시되는 공통 조건과 각 사례만의 조건은 모둠 설명과 자료에서 겹친 분류를 비교한 것이다. 사례 사이의 모든 차이나 원인·정답을 판정하지 않는다. 원문 관찰, 확인되지 않은 조건, 규칙 범위와 자료 한계·출처를 함께 살펴본다. 야구 원본은 티볼과 공통 기술만 부분 비교하며, 사용자 시범 수용은 교사·전문가 검토가 아니다.

**교사와 전술판에서 검토**를 누르면 이 탭의 메모리에 종목·익명 상황 문장·선택 사례 ID 최대 두 개만 임시로 둔다. 자료 검색 결과가 없어도 사례를 선택하지 않은 질문으로 교사 검토를 요청할 수 있다. 교사는 교사 메뉴에서 PIN을 풀고 학급 전술판의 **모둠 요청 가져오기**를 직접 눌러야 한다. 앱이 현재 자료에서 ID를 다시 확인하며 없어진 사례를 추정해 복원하지 않는다. 가져오기는 한 번만 사용할 수 있고 전술판 배치·회고를 수정하거나 서버에 보내지 않는다. 요청은 15분 후 만료된다.

입력 변경, 새 검색, 학생 패널 닫기 또는 **모둠 초기화**는 이전 비교와 대기 중 요청을 지운다. 새로고침이나 탭 종료 후에는 임시 요청이 남지 않는다. 화면 이탈 시 진행 중인 AI 선택은 취소를 요청한다. 브라우저 검사는 개발 환경과 모의·미설치 모델 기준이며 교사·학생의 실제 수업 및 Android 실기기 검증을 대신하지 않는다.
