# 농구 동작 피드백 안내

기준일: 2026-11-06. S4.4는 S4.3의 READY→SHOOT 동작 신호에 선택적인 화면 강조, 짧은 효과음, 순간 이미지 표시를 더한다. 세 옵션은 기본 꺼짐이며 사용자가 명시적으로 켤 수 있다. 이는 골 성공이나 슛의 기술적 정확성, 점수·성적을 뜻하지 않는다. 전체 S4 단계와 현장 검증은 계속 진행 중이다. 동작 인식 기준은 [S4.3 안내](S4-shot-guide.md), 개발 검사는 [S4.4 검증 기록](stage-S4-feedback-validation.md)를 참고한다.

## 사용 방법

카메라와 전신 확인, 교사 설정의 농구 동작 확인을 먼저 켠다. 피드백 옵션은 필요한 것만 각각 켠다. 화면 강조는 팔 펴기 감지 때 잠깐 표시되며 플래시가 아니다. 효과음은 브라우저가 사용자 동작 중 오디오를 허용하지 않으면 재생되지 않을 수 있다. 순간 이미지는 감지 이벤트를 만든 추론 입력 프레임에서 생성되며 지연 재생 영상의 현재 화면과 시각이 다를 수 있다. 화면에 표시되는 시각은 추론 입력 시점이다.

표시된 순간 이미지는 최신 한 장만 메모리에 유지된다. **지우기**를 누르거나 카메라·전신 분석을 중단하고, 화면을 떠나거나 맥락·설정을 바꾸면 관련 이미지와 미완료 결과를 정리한다. 피드백 옵션은 현재 화면 세션의 임시 선택이며 앱 설정으로 저장되지 않는다.

이미지는 최대 320×640으로 제한한다. 프레임 복제가 250ms 안에 끝나지 않으면 그 이미지는 생략하고 분석을 계속한다. 미완료 복제는 한 개로 제한하며 늦게 끝나면 폐기한다. PIN 초기화 성공과 페이지 이탈에서는 피드백 옵션도 모두 꺼진 기본값으로 돌아간다.

## 개인정보와 한계

피드백은 이벤트 프레임을 짧게 축소해 화면에만 표시한다. 캡처 이미지·각도·시도 기록은 자동으로 저장·업로드되지 않는다. 이벤트 중복은 한 번만 알리고, 오래되거나 맥락이 바뀐 비동기 결과는 폐기한다. 브라우저 메모리·오디오 기능 제약으로 선택 기능이 실패해도 기본 카메라와 촬영 흐름을 계속 사용할 수 있어야 한다.

실제 Android·학교 환경, 장시간 사용, 여러 사람·조명·가림 조건의 정확도는 확인 대기다. 정지 fixture 추론과 합성 동작 시퀀스는 실제 슛의 화면 효과·소리·캡처 품질이나 스포츠 정확도를 증명하지 않는다. 자동 영속 저장, 업로드, 새 시도/관절 로그는 S4.4에 포함하지 않는다.
