# 경기 사례 조건 검색 구현 기록

요청의 행동·경기 국면·공간·의사소통·규칙 관련 표현과 자료에 기록된 장면의 지원 조건을 비교한다. 시범 조사 자료는 장면 비교 연결 중 일치한 것만 중복 제거해 제공하며 항상 부분 관련이다. 야구 자료는 티볼 공통 행동만 부분 비교하고 규칙 적용은 미확인으로 표시한다. 순수 규칙 질문은 야구 후보를 제외한다. 요청에서 실패한 행동과 출처의 성공 행동은 차이를 표시하며 부분 비교할 수 있다. 기존 자료도 기록된 관찰 범위와 조건을 비교하며 A등급만으로 직접 관련으로 판단하지 않는다. 사용자 시범 수용은 교사나 전문가의 검토와 별개다.

출처의 missing 조건 및 맥락은 검색 지원 사실로 인덱스하지 않는다. 목표와 전술판은 본문에서 일치하는 조건이 확인된 후 후보 순서에만 영향을 준다. 평가 질문 본문과 질문별 정답은 검색 자료로 사용하지 않는다. 모델은 서버가 제시한 ID만 선택할 수 있다. 후보가 없으면 모델을 호출하지 않는다.

한국어 표현에 대한 제한된 규칙과 관찰 조건 비교이므로 동의어·문장 범위·부정의 해석에 한계가 있고 일부 관련 장면이 빠지거나 부분 관련이 과하게 나타날 수 있다. 직접 관련도 문맥이 완전히 같다는 판정이 아니다. 450개 질문의 전수 평가, 실제 3B 모델 평가, 전문가 검토 및 학교 규칙 확인은 수행하지 않았다.

검사: `node --test tests/tactics-relevance.test.cjs tests/tactics-pilot.test.cjs tests/tactics-sharing.test.cjs tests/tactics-board.test.cjs` (23개 통과), `node tests/browser-connected-tactics.cjs` (모의 모델 브라우저 통과). 후속 단계 5에서는 검색 누락과 출처·관련성·불확실성 설명을 별도로 평가한다.
