# 카메라 안정화 및 클립 검증 기록

이 문서의 MediaRecorder 클립 수치는 이전 방식의 기록이다. 현재 클립 구현과 30초 상한 검증은 [2단계 기록](stage-2-validation.md)을 따른다.

날짜: 2026-11-05 (한국 시간)

## 기준

사용자가 지정한 기준 기기는 갤럭시 탭 A9+다. 실제 기기는 아직 확보하지 않았으며 아래 결과는 클라우드 환경의 Linux Chromium과 가상 카메라에서 얻었다. Android·Chrome 버전 및 RAM 구성에 따른 결과는 별도 확인해야 한다.

## 구현

- 카메라 권한 거부, 카메라 없음, 다른 앱 사용 등 시작 오류를 구분하고 지속적으로 복구 안내를 표시한다.
- 시작 요청과 프레임 처리에 세대 번호를 적용한다. 촬영 중단 후 뒤늦게 도착한 스트림·프레임이 새 촬영에 들어오지 않도록 한다.
- 연결 종료·일시 음소거·영상 정지·화면 이탈 시 촬영을 중단한다. 기존 실시간 버퍼를 비우고, 사용자가 눌러 새 촬영을 시작하게 한다.
- 선택 화면의 스냅샷은 실시간 버퍼와 분리해 유지한다. 저장이 중단된 경우 앱에 복귀해 선택한 장면을 재시도할 수 있다.
- 촬영 시각은 시스템 시계 변경에 영향을 덜 받도록 단조 증가하는 성능 시계를 사용한다. 7일 만료 판단에는 실제 날짜 시계를 사용한다.
- 프레임 버퍼를 독립 모듈로 분리하고, 시각 범위·바이트 수·프레임 수 제한을 적용한다.
- 지원 기기에는 화면 꺼짐 방지를 요청한다. 이 기능이 거부되어도 앱을 사용할 수 있다.

## 통과한 확인

| 확인 | 결과 |
| --- | --- |
| 합성 시각의 40분 입력 | 최근 5분의 3,001개 프레임만 남음. 각 8KiB 샘플의 페이로드 합계 24,584,192바이트. 실제 카메라의 메모리 측정은 아님 |
| 메모리·프레임 제한 | 오래된 프레임 삭제, 바이트·프레임 상한 준수, 과도한 단일 프레임과 역순 시각 거부 |
| 스냅샷 | 실시간 버퍼가 순환하거나 비워져도 선택한 장면 유지 |
| 권한·장치 오류 | 거부·카메라 없음·사용 중 오류를 구분하고 버튼 재시도 가능 |
| 지연된 권한 결과 | 중단 후 도착한 스트림을 종료하고 버퍼에 추가하지 않음 |
| 카메라 연결 중단 | 실시간 버퍼 삭제, 재시작 안내, 사용자 요청 후 새로운 시각 범위로 시작 |
| 화면 이탈 이벤트 | 촬영 중지, 자동 재시작 없음, 저장 중이었다면 파일을 저장하지 않고 재시도 안내 |
| 저장 재시도 | 화면 복귀 후 이미 선택한 구간을 저장 가능 |
| 세션 종료 | 스트림·프레임 정리 및 수업용 암호화 키 해제 |
| 브라우저 오류 | 위 브라우저 시나리오 중 처리되지 않은 페이지 오류 없음 |

## 실제 출력 파일 측정

WebM을 복호화한 뒤 ffprobe로 마지막 패킷의 시각과 길이를 확인했다. 모든 출력에는 비디오 스트림만 있었고 오디오 스트림은 없었다. 파일은 가상 영상이며 검사 후 임시 파일을 삭제했다.

| 선택 길이 | 파일 패킷 기준 길이 | 인코딩 경과 시간 | 파일 크기 |
| --- | ---: | ---: | ---: |
| 5초 | 5.094초 | 5.0013초 | 107,580바이트 |
| 15초 | 15.010초 | 15.0015초 | 345,748바이트 |
| 30초 | 30.060초 | 30.0012초 | 680,721바이트 |

측정값은 모두 선택 길이 대비 0.3초 이내 오차다. MediaRecorder와 브라우저 타이머의 프레임 마감 때문에 출력이 선택 길이보다 수십 밀리초 길 수 있다. 따라서 엄밀한 ‘출력 파일 30.000초 이하’는 아직 보장하지 않는다. 현재 제한은 선택 가능한 구간의 최대 길이 30초다. 엄밀한 파일 길이 상한이 필요하면 패킷 절단 또는 타임스탬프를 직접 제어하는 인코딩 방식을 추가해야 한다.

## 미검증 항목

- 갤럭시 탭 A9+에서의 카메라 화질, 실제 지연, 발열·배터리·전체 메모리, 40분 연속 실행.
- Android 화면 잠금·Chrome 백그라운드 정책·실제 권한 철회. 이번 검사는 가상 장치와 결정적인 이벤트 처리를 확인한 것이다.
- 80MiB 실시간 버퍼 외에 선택 스냅샷·이미지 디코딩·인코더가 쓰는 전체 메모리. 실시간 버퍼 한도는 앱 전체 메모리 한도가 아니다.
- 7일 삭제·PIN 수명·손상 파일·저장 공간 부족·PWA 업데이트의 확장 검증은 후속 개발 묶음에서 진행한다.
