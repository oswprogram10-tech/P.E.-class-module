# 전신 확인 첫 묶음 사용·설치 안내

기준일: 2026-11-06 (한국 시간).

이 안내는 S4.1~S4.2의 전신 확인 기초 사용·설치 범위를 기록한다. 현재 앱의 S4.3 농구 READY→SHOOT 동작 확인은 별도 [농구 동작 안내](S4-shot-guide.md)와 [검증 기록](stage-S4-shot-validation.md)을 참고한다. 아래의 “포함하지 않는다”는 문장은 이 기초 안내 묶음의 범위에 대한 설명이다.

S4.1~S4.2의 개발환경 잔여 확인은 완료했다. 공식 Pose Landmarker Lite float16 v1 파일을 설치했고, 모델 카드의 모델 계열 라이선스 근거를 기록했으며, 실제 worker 추론·offline 재실행·짧은 기본 카메라 동시 측정을 확인했다. Android 실기기·학교 수업·장시간 사용 검증은 남아 있다. [검증 기록](stage-S4-foundation-validation.md)과 [자산 기록](pose-assets.json)을 따른다.

## 기본 사용 흐름

1. 기존 PIN·카메라·지연 영상·클립 흐름을 사용한다. 전신 확인은 선택 기능이며 준비 실패가 기본 촬영을 막지 않는다.
2. 배포본의 자산이 설치되어 있고 같은 출처로 제공되는지 확인한 뒤 **전신 확인 준비**를 누른다. SDK·WASM·모델을 검사하고 기본 셸과 별도 캐시에 보관한다. 준비 중단·재시도·준비 파일 지우기를 제공한다.
3. 준비가 끝나면 **전신 확인 사용**을 켠다. 별도 worker가 축소한 카메라 프레임을 처리한다. 원본 영상과 관절 좌표는 AI 서비스로 전송하지 않는다.
4. 필요한 관절의 신뢰도·화면 위치·몸 크기를 검사한다. 누락·가림·낮은 신뢰도·화면 밖 이탈·작은 몸에는 안내하고 확인 가능 상태를 취소한다. 조건을 연속 3회 충족하면 안정적으로 확인된 상태를 표시한다.
5. 음성 안내는 기본 꺼짐이다. 기기에 한국어 음성이 있을 때 선택할 수 있으며, 같은 안내를 반복 재생하지 않는다. 화면 이탈·기능 중단 때 음성을 정리한다.
6. 장면 선택·저장·화면 전환·촬영 중단·응답 지연 때 과거 결과를 현재 상태로 사용하지 않는다. 선택·인코딩 중에는 AI worker를 중단하며, 저장 완료·취소 뒤 기본 촬영 흐름을 계속한다.

전신 확인은 필요한 관절이 화면에 있는지 보는 준비 조건이다. 이 S4.1~S4.2 기초 묶음은 농구 READY/SHOOT, 팔 각도, 자동 캡처, 시도 기록과 성적 산출을 다루지 않는다. 현재 구현된 S4.3 범위는 별도 안내를 참조한다.

## 모델과 이용조건

공식 모델은 고정 URL의 `Pose Landmarker Lite float16 version 1`이다.

```text
https://storage.googleapis.com/mediapipe-models/pose_landmarker/pose_landmarker_lite/float16/1/pose_landmarker_lite.task
```

설치 파일 크기는 5,777,746 bytes, SHA-256은 `59929e1d1ee95287735ddd833b19cf4ac46d29bc7afddbbf6753c459690d574a`다. 모델 카드는 BlazePose GHUM 3D 계열의 Lite 모델을 설명하고 `LICENSED UNDER: Apache License, Version 2.0`으로 표시한다. 정확한 task archive는 별도 라이선스 파일이나 공개 provider digest를 포함하지 않으므로, 계열 카드와 개별 archive의 증거 수준을 [자산 기록](pose-assets.json)에 구분해 적었다. MediaPipe SDK 자체의 Apache-2.0 파일은 모델 파일 라이선스를 대신하지 않는다.

초기 검증 기록의 HTTP 403은 당시 제한 환경에서 모델 호스트가 허용되지 않았을 때의 상태다. 현재 환경은 최신 관찰이 유효하고 네트워크 정책이 적용됐으며, `storage.googleapis.com` 허용을 확인한 뒤 Sol이 공식 모델을 설치했다. 이 팀은 환경설정을 변경하거나 게시하지 않았다.

Model Card의 적용 범위·한계도 확인한다. 단일 인물 추정용이며 여러 사람, 머리 미노출, 약 4m 초과, metric 정확도가 필요한 깊이, 감시·신원 인식에는 적합 범위가 아니다. 얼굴 위치·크기·방향에 민감하고 저조도·노이즈·움직임·얼굴 가림은 품질 저하와 흔들림을 일으킬 수 있다. 학교 연령 아동·농구 자세·성적 판단에 대한 정확도를 보증하지 않는다.

저장소에서 모델을 다시 받아야 하면 공식 URL만 사용하고 기존 proxy/TLS 검증을 유지한다.

```sh
cd /workspace/P.E.-class-module
node scripts/fetch-pose-model.cjs
```

설치기는 고정 HTTPS 주소, 파일 구조와 로컬 SHA-256 핀을 확인한다. 같은 공식 파일은 재사용하며 다른 해시를 기존 핀 위에 덮지 않는다. 제공자 서명이나 독립 공개 checksum을 확인했다고 주장하지 않는다. 실제 배포 전에는 셸·모델 자산을 같은 배포본에 포함하고 실제 배포 경로에서 준비·offline 재사용을 확인한다. 이번 검증은 외부 게시·배포를 수행하지 않았다.

## 보관·자원 수명

- AI 경로는 이미지·랜드마크·점수·시도 로그를 영속 저장하지 않는다. 이후 S4.4에서 순간 이미지를 명시적으로 켜면 최신 1장을 메모리에만 표시한다. [피드백 안내](S4-feedback-guide.md)를 따른다. 기존 임시 카메라 버퍼와 학생이 저장한 클립·성찰은 원래 보관 정책을 따른다.
- 기본 서비스 워커 셸은 현재 **v12**이다. 큰 SDK/WASM·모델 자산은 `pe-loop-pose-*` 별도 캐시에 준비한다. 모델 미설치가 기본 앱의 오프라인 설치 전체를 실패시키지 않는다.
- 자산은 같은 출처에서 가져오고 캐시 재사용·실행 전 SHA-256을 검사한다. 준비 파일 지우기는 현재 버전 AI 캐시만 삭제하며 학생 클립은 삭제하지 않는다.
- worker는 한 번에 요청 하나를 처리하고 기본 약 333ms 간격으로 축소 프레임을 보낸다. 결과가 늦으면 빈도를 낮춘다. 이 간격은 제어값이다.
- 2초 넘은 결과는 확인 가능 상태에서 제외하고 worker 응답은 5초 제한을 둔다. 중단·초기화·페이지 종료 때 worker, 전송 중 bitmap과 음성을 정리한다.

실제 모델 동시 측정은 Linux Chromium·CPU/WASM·가상 카메라에서 4초씩 한 것이며 Android 성능·전체 메모리·발열·40분 촬영의 증거가 아니다. Android 실기기·학교 수업 확인과 S4 범위 확장은 각각 별도 후속 조건이다. 이전 기록 당시 S4.3은 시작하지 않았으며 현재는 명시적 요청으로 별도 구현·검증했다.
