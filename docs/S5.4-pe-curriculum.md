# S5.4 체육 성취기준 출처와 평가 연결

[교육부 고시 제2022-33호](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=93458&lev=0&statusYN=W)의 붙임 2에서 **별책 11 체육과 교육과정**을 확인했다. **2. 내용 체계 및 성취기준 → 나. 성취기준**의 초등학교 3~4학년, 5~6학년과 중학교 1~3학년에 있는 운동·스포츠·표현 코드 100개를 앱 목록과 대조했다. 화면에 표시되는 문장은 해당 기준을 찾기 위한 짧은 요약이다. 정확한 문구와 해설은 저장된 출처 링크에서 붙임 2를 열고 코드를 검색한다.

[국가교육위원회 2024-3호 공고](https://www.ne.go.kr/user/bbs/BD_selectBbs.do?q_bbsDocNo=20240927163706792&q_bbsSn=1016)와 [2026-1호 개정문](https://www.law.go.kr/admRulInfoP.do?admRulSeq=2100000273516&chrClsCd=010202&urlMode=admRulRvsInfoR)도 확인했다. 두 일부 개정의 변경 대상은 별책 1~4와 15이며, 이 목록의 체육과 별책 11은 원 고시를 따른다. 자료 확인일은 2026-11-17이다.

| 적용 학년 | 목록 사용 시작 | 원문 학년군과 코드 수 |
| --- | --- | --- |
| 초등학교 3·4학년 | 2025학년도 | 초등 3~4학년군, 23개 |
| 초등학교 5·6학년 | 2026학년도 | 초등 5~6학년군, 26개 |
| 중학교 1학년 | 2025학년도 | 중학교 1~3학년군, 51개 공통 |
| 중학교 2학년 | 2026학년도 | 같은 중학교 학년군 |
| 중학교 3학년 | 2027학년도 | 같은 중학교 학년군 |

중학교 1~3학년용 코드는 국가 교육과정의 학년군 목록이다. 실제 수업 배치는 학교 교육과정과 평가 계획에 따라 교사가 선택한다. 이번 목록은 2022 개정 일반 체육의 초등 3~6학년과 중학교 범위다. 이전 개정판, 초등 1~2학년 통합교과, 특수교육, 고등학교 과목은 연결 목록에서 미지정으로 둔다.

## 교사 사용법

1. 교사 PIN → **학급·제출 → 교사 루브릭 · 근거 평가 · 문안 승인**에서 평가 학생과 해당 학년도의 교사 루브릭을 선택한다.
2. **국가 체육 성취기준 (선택)**에서 실제 적용 학년을 선택한 뒤 운동·스포츠·표현 중 수업과 맞는 코드를 고른다. 학급명, 학생 이름, 스포츠 이름에서 기준을 자동 선택하지 않는다. 현재 묶음에 해당 기준이 없으면 미지정으로 저장할 수 있다.
3. 평가 초안을 저장하면 그 시점의 코드·학년·학년도·요약·고시·원문 위치를 평가와 함께 PIN으로 암호화해 보관한다. 나중에 평가를 열어 **저장 당시 성취기준**에서 확인한다. 목록의 요약 열람·선택은 오프라인에서도 작동하고 원문 사이트 열기는 인터넷이 필요하다.
4. 기준을 수정·해제하면 이전 출처가 **변경 전 성취기준 보기**에 남는다. 평가와 이를 사용한 승인 문안은 초안으로 돌아가므로 교사가 내용을 다시 확인하고 승인한다. 기존의 연결 없는 평가와 교사 루브릭은 그대로 사용할 수 있다.

예를 들어 초등 5~6학년의 게임 중 전략 활용을 관찰할 때 `6체02-06`을 검토할 수 있다. 중학교의 영역형·필드형·네트형 경기에서 전략 활용을 평가할 때 후보는 각각 `9체02-12`, `9체02-15`, `9체02-18`이다. 같은 종목이라도 평가 목표가 기술 수행이나 팀 협력이면 다른 기준이 맞을 수 있다. 앱의 지식·기능·태도 4수준과 점수, 학생 서술은 교사가 정한다.

이 기능은 평가와 국가 교육과정 사이의 참조를 기록한다. PAPS 배점과 기존 문안 CSV 형식에는 영향을 주지 않는다.
