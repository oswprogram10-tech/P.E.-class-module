# 5단계 구조 계약 실행 기록

`node scripts/evaluate-tactics-answer-contract.cjs`는 450개 합성 질문 각각에 종목·질문 문장·overall만 넣어 브라우저의 실제 공유 검색 API와 `TacticsLocalAdvisor.search`를 호출한다. 질문 ID와 기존 연결은 전달하지 않는다. 75개 상황군에 문항 6개씩이며 티볼 문항은 규칙과 경기 조건도 달라진다. 독립된 실제 경기 사례 450개가 아니다. 실행 결과와 입력 및 구현의 SHA-256은 [JSON](tactics-stage5-evidence-contract.json)에 있다. 재실행 후 해시가 달라지면 수치와 결과를 이전 실행과 직접 비교할 수 없다.

2026-11-16 실행: 450문항, 질문별 검색 반환 2,019건(중복 포함, 고유 카드 136개), 빈 결과 124개, 검색 참조에서 search 결과 카드로의 지정 필드 변형 0개. 관찰·맥락·원종목·지원/누락·미확인·차이·규칙·출처·검토 상태를 비교했다. 단, 이는 **검색 참조에서 search 카드까지의 구조 동일성**이며, 원자료에서 검색 참조로 오는 과정이나 실제 UI 렌더링의 보존을 증명하지 않는다. 기존 검색 대조 기록의 원본 범위 검사는 별도이며 의미 타당성을 판정하지 않는다.

모델 대신 합성 ID를 이용하여 제공 후보 선택과 빈 선택을 허용하고 중복·미제공 ID·추가 필드·2개 초과 등 7개 입력을 거부하는지 검증했다. `preBudgetOfferedIds`는 토큰 예산 적용 전 상위 2개이지 실제 모델에 전달된 최종 목록이 아니다. 모델 호출, 선택 정확도, 모델 결과의 projection, 문장 의미 또는 전문가 검토를 수행한 결과가 아니다. 검색 후보 전체에 대한 search 카드의 구조 검사는 모델이 그 후보를 실제 선택했다는 뜻이 아니다.

경계 사례 TE-14-06은 후보가 0개다. 참고 연결 CSV의 TBX-01은 `evidence-boundary-reference`이며 무음 영상의 확인 사례가 아니다. 따라서 이 실행에서 장면 근거로 반환되지 않았다. 이 한 질문의 결과가 다른 모든 경계 요청의 의미 안전성을 보장하지는 않는다. 티볼에서 야구 사례가 나오더라도 원종목과 규칙 미확인 상태가 별도로 남아야 한다.

75개 상황군 대표별 카탈로그 의미감사는 [별도 AI 감사](tactics-stage5-evidence-semantic.md)에 기록했다. 구조 계약 수치와는 다른 판단이며 외부 원문이나 사람·전문가 검토가 아니다.

기존 연결 참고목록(정답 아님)과 검색 순위의 탐색적 대조에서는 256문항이 검색 결과 어느 위치에서든 참고 ID와 겹쳤다. 그중 204문항은 토큰 예산 적용 전 상위 2개 안에 겹치는 ID가 있었고, 52문항은 3위 이하에서만 겹쳤다. 이는 좋은 후보 52개를 놓쳤다는 판정이나 정확도가 아니다. 실제 토큰 예산은 두 후보 중 하나를 추가로 줄일 수 있으며 실제 모델 입력·선택은 별도로 측정해야 한다.
