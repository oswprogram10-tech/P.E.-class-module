# S5.3~S5.9 개발 검증 기록

기록 기준일: 2026-11-06. 변경은 로컬 작업 트리에만 남겼고 게시하지 않았다. Android·학교 현장·발열·실제 40분 연속 사용은 사용자의 이전 범위 지시에 따라 이번 검증에서 제외했다.

## 완료한 로컬 구현

- **S5.2.3:** `paps-reports.js`는 기록된 수치만 학생별 추이로 나열/그린다. 학년·평가표 구분이 명시되지 않으면 추이를 만들지 않는다. 학급 분포는 동일 학급·학년도·종목에서 각 기록에 저장된 학년/평가표/기준 버전으로 등급을 계산하고 결측·기준 불일치를 따로 센다. 원자료 CSV는 학생과 행을 교사가 선택하고 확인을 눌러 내려받으며 출처/버전/단위를 포함한다. NEIS 파일이라고 표기하지 않는다.
- **S5.3:** 여섯 개 저작권 미디어 없는 텍스트 동작 안내, 안전 주의와 목표 요소를 등록했다. 각 항목은 교사가 안전과 해당 학급 적합성을 직접 체크하기 전에는 사용하지 못한다. 세 구간 합계 900초 루틴, 일시정지·재개·건너뛰기·대체 동작을 연결했다. 이 체크는 전문가 검토·학교 승인 완료를 대신하지 않는다.
- **S5.4:** 교사가 자체 지식·기능·태도 기준과 4수준 설명을 입력·수정한다. 기준 변경 이력과 버전을 보존하고 기존 평가는 생성 당시 기준 사본을 유지한다. 같은 학생의 교사 관찰·성찰·제출 클립만 근거로 연결하며 평가 수준/서술/근거의 변경 이력을 기록한다. 모두 채점하고 교사가 승인해야 승인 상태가 된다. 공식 성취기준으로 연결된 템플릿은 없다.
- **S5.5:** 교사가 문안을 직접 작성·편집하고 승인한다. 학생 한 명의 승인된 평가만 근거로 포함할 수 있다. 원 평가가 수정되면 기존 문안 승인은 해제한다. 선택 후 확인 창을 거치는 로컬 CSV는 수식 입력을 무력화하고 셀 안 줄바꿈을 정리하며 NEIS 비호환임을 표시한다. 외부 AI·직접 NEIS 전송은 없다.
- **S5.6:** PWA의 2022-11-06 출시일 하한, 학생·보호자 세션 동의 확인, OS 권한 전제, in-memory 심박 표시, 오래된 값 제거, 끊김 공백과 수동 재연결을 추가했다. 실제 Galaxy/Apple 워치 또는 네이티브 연동 앱은 없다. 전용 검증은 [웨어러블 브리지 검증](stage-S5.6-wearable-validation.md)에 분리했다.
- **S5.7:** 교사 화면에서 순서 활동과 선택 퀴즈/정답을 만들고 UUID만 든 QR을 생성한다. 지원 시 BarcodeDetector를 쓰며 수기 UUID 입력을 대체로 제공한다. 익명 응답은 PIN 암호화 데이터로 저장하고 응답 ID 중복 재시도, 순서, pause/resume/restart를 지원한다. 교사는 미션 단위 삭제를 확인할 수 있고 해당 미션의 세션·응답도 함께 제거된다. GPS와 학생 이름/ID 결합은 없다.
- **S5.8:** 익명 팀·토큰·이동/패스 방향·공격/수비 표식과 실행 전후 스냅샷을 SVG로 표시한다. 좌표 입력으로 조작할 수 있고 여러 판의 선택·복제·초기화·회고를 제공한다. 알려진 학생 이름·번호·ID가 회고에 포함되면 거부한다. 판은 같은 기기 로컬 저장이며 외부 공유·AI 추천은 없다.
- **S5.9:** 새 배열은 기존 PIN 저장소 상태를 안전하게 초기화한다. 학급 삭제/만료 시 루브릭·평가·문안·루틴 승인·QR·전술 데이터를 제거한다. 서비스워커 캐시를 v21으로 갱신했다.

## 검증 명령

- `node --test tests/*.test.cjs` — 119개 통과. 로컬 HTTP/zip이 필요한 기존 테스트와 웨어러블 브리지 단위 검사까지 포함했다.
- `node tests/browser-paps-reports.cjs` — 추이 범위·공식 등급 분포·확인형 선택 CSV 다운로드 통과.
- `node tests/browser-classroom-tools.cjs` — 교사 자체 루브릭, 근거 승인, 직접 작성 문안, 검토형 15분 루틴, offline QR 2단계 퀴즈·익명 응답·미션 단위 삭제, 전술판 복제·선택, 확장 자료 학급 삭제 통과.
- `node tests/browser-classroom-measurements.cjs` — PAPS 수기 기록·수정 이력·삭제 회귀 통과.
- `node tests/browser-wearable-bridge.cjs` — 가상 네이티브 브리지로 학생·보호자 동의, 심박 표시, 연결 공백, 교사 재연결, 동의 철회와 PIN 잠금 시 종료 통과. 실제 시계 테스트가 아니다.
- `node tests/browser-pwa.cjs` — 오프라인 재실행·서비스워커 업데이트·캐시 실패 처리 통과.
- `node --check`로 신규 브라우저 모듈 구문을 확인했다.

브라우저 검사는 이 개발 환경의 Chromium 및 가상 로컬 서버에 한정한다. QR 실제 카메라 인식, 장치별 BarcodeDetector, 실제 Galaxy/Apple Watch 연결, Android·학교 네트워크·발열·실제 40분 지속 사용은 확인하지 않았다. 공식 교육과정 대조, NEIS 양식, 실제 수업에서의 콘텐츠 안전성도 대기한다. 세부 지원 구분은 [S5 지원 환경표](S5-support-matrix.md)와 [웨어러블 브리지 검증](stage-S5.6-wearable-validation.md)에 있다.
