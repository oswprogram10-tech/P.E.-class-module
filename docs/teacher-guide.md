# 교사용 안내서 — 설치와 수업 운영 (초안)

상태: **G02 초안**. 실제 Android Chrome에서 설치·오프라인·수업 사용을 검증한 기록이 아니다. 안내 절차는 현재 코드와 개발용 브라우저 검증을 기준으로 작성했으며, 실제 기기에서의 설치 안내 검증은 **대기** 중이다.

접속 주소: `{{HTTPS_BASE_URL}}` — **아직 정해지지 않았다.** 호스팅 위치와 주소가 결정되면 이 자리표시자를 실제 HTTPS 주소로 바꾼 뒤 배포한다.

## 1. 준비물

- 안드로이드 태블릿과 최신 Chrome
- 흔들리지 않는 거치대
- 전원 케이블 또는 충전된 배터리
- 첫 실행 시 인터넷 연결(앱 셸을 준비할 때 필요)
- 태블릿을 세울 공간과 학생이 2~3걸음 물러설 여유

실제 학교 사용과 배포에는 HTTPS가 필요하다. 카메라, PIN 암호화, 오프라인 앱 셸 준비는 HTTPS 주소를 전제로 한다. 개발용 `localhost` 미리보기는 예외적으로 동작할 수 있지만, 이는 실제 배포나 Android 설치 검증을 대신하지 않는다. `http://` 주소(개발용 `localhost` 제외)나 `file://`로 직접 연 화면에서는 카메라와 PIN 기능을 사용할 수 없다. HTTPS 호스팅 주소는 아직 정해지지 않았고, 배포 준비(G01)도 대기 상태다.

## 2. 앱 설치

1. 태블릿의 Chrome을 열고 `{{HTTPS_BASE_URL}}` 주소로 이동한다.
2. 화면이 끝까지 열릴 때까지 기다린다. 첫 실행은 앱 셸을 내려받아야 하므로 인터넷 연결이 필요하다.
3. 화면 아래에 **앱 설치** 버튼이 보이면 누른다.
4. 버튼이 없으면 Chrome 오른쪽 위 **⋮** 메뉴에서 **앱 설치** 또는 **홈 화면에 추가**를 선택한다.
5. 홈 화면에 생긴 **PE Loop** 아이콘으로 연다. 일반 Chrome 탭으로 열어도 사용할 수 있다.

> 실제 Android 기기에서 설치 버튼·⋮ 메뉴·홈 화면 추가가 어떻게 보이는지는 아직 확인하지 않았다. 설치가 되지 않으면 [문제 해결표](troubleshooting.md)의 확인 순서를 따른다.

## 3. 첫 실행과 교사 PIN

1. 화면 오른쪽 위의 방패 모양 **교사 메뉴 열기** 버튼을 누른다.
2. **교사 PIN을 설정해 주세요** 화면에서 숫자 6자리 PIN을 입력하고, 같은 PIN을 한 번 더 입력한다.
3. **PIN 만들기**를 누른다.

PIN은 저장한 클립 목록과 수업 설정을 보호한다. PIN은 화면에 다시 표시되지 않으며, 잊으면 복구할 수 없다. 이 안내서에는 예시 PIN을 넣지 않는다. 실제 PIN을 문서·칠판·학생에게 알려 주지 않는다.

- 교사 메뉴를 열 때마다 PIN을 입력한다. 카메라를 시작하려면 교사 세션이 필요하며, 한 번 PIN을 입력한 뒤 **잠그기**를 누르지 않았다면 카메라 시작은 추가 PIN 없이 진행된다.
- **잠그기**를 누르면 교사 권한이 끝난다. 이후 카메라를 시작하거나 클립을 저장하려면 PIN을 다시 입력해야 한다.
- 현재 일반적인 PIN 변경 기능은 없다. PIN을 바꾸려면 모든 로컬 클립을 삭제하는 초기화를 해야 한다. [11. PIN 분실과 초기화](#11-pin-분실과-초기화)를 참고한다.

## 4. 수업 시작

### 태블릿 거치와 촬영 구도

- 태블릿을 학생 눈높이에 맞추고 흔들리지 않게 고정한다.
- 학생은 태블릿에서 **2~3걸음** 떨어져 **머리부터 발끝까지** 화면에 들어오게 선다.
- 전면 카메라를 사용한다. 창문을 등지면 학생 얼굴이 어두워질 수 있으므로 빛 방향을 확인한다.
- 가로·세로 화면을 모두 사용할 수 있지만, 수업 중에는 거치 상태를 바꾸지 않는 편이 좋다.

### 카메라 시작

1. **카메라 시작**을 누른다.
2. 아직 PIN을 만들지 않았거나, PIN을 입력하지 않았거나, **잠그기**로 세션을 끝냈다면 교사 PIN 화면이 먼저 열린다. PIN을 만들거나 입력한다.
3. PIN 화면을 닫고 다시 **카메라 시작**을 누른다. 이때 Chrome의 카메라 권한 요청이 나타나면 **허용**을 선택한다.
4. 화면이 **카메라 연결 중…** 을 거쳐 촬영 상태로 바뀌는지 확인한다.

카메라 권한은 앱을 열었다는 이유만으로 요청되지 않는다. 교사가 **카메라 시작**을 누른 뒤에만 요청된다. 수업 중에는 앱을 전면에 두고 화면이 꺼지지 않게 한다.

### 지연 시간과 준비 상태

- 기본 지연 시간은 20초다.
- **교사 메뉴 열기 → 수업 설정 → 지연 재생 시간**에서 **1~60초** 사이로 조절한다.
- 카메라를 켠 직후에는 설정한 지연 시간만큼 영상이 쌓일 때까지 기다린다. 화면에 **지연 영상 준비 중 · N초**가 표시된다.
- 준비가 끝나면 **지연 영상 재생 가능**으로 바뀌고 지연 영상이 재생된다.
- 임시 영상은 최근 5분만 순환 보관한다. 5분이 지나면 오래된 장면부터 사라진다.

## 5. 학생 저장 흐름

1. 학생이 **마음에 드는 장면 저장**을 누른다. 카메라가 켜져 있고 5초 이상 영상이 쌓여야 버튼이 활성화된다.
2. **장면 끝나는 시점**을 움직여 저장할 장면의 끝을 고른다.
3. **저장할 길이**를 **5~30초**에서 5초 단위로 고른다. 기본값은 15초다.
4. 학생 **이름**(1~24자)과 **번호**(1~9999)를 입력한다.
5. **이 장면 저장**을 누르고 **클립을 만드는 중이에요 · N%** 표시가 끝날 때까지 기다린다.
6. 저장이 끝나면 완료 안내가 표시된다.

저장되는 클립은 **소리 없이** 만들어지고 **최대 30초**다. 영상과 이름·번호는 이 태블릿의 IndexedDB에만 암호화되어 저장되며 서버로 전송되지 않는다.

저장 중에는 화면을 바꾸거나 태블릿을 잠그지 않는다. 저장 중 앱이 백그라운드로 이동하면 저장이 중단되고, 앱으로 돌아와 같은 선택으로 다시 시도해야 할 수 있다.

학생에게는 [학생용 한 장 안내](student-quick-guide.md)를 인쇄해 보여 준다.

## 6. 교사 메뉴 — 클립 목록·재생·삭제·잠금

1. 오른쪽 위 **교사 메뉴 열기**를 누르고 PIN을 입력한다.
2. **저장한 클립** 탭을 연다. 탭 이름 옆 숫자는 현재 목록의 클립 수다.
3. **영상 보기**를 누르면 해당 클립이 재생된다. 한 번에 하나씩 재생된다.
4. 각 클립의 **×** 버튼을 누르면 삭제 확인 창이 열린다. **삭제하기**를 누르면 그 클립이 삭제된다. 삭제한 영상은 복구할 수 없다.
5. **잠그기**를 누르면 교사 권한이 끝나고 클립 목록이 닫힌다. 카메라가 켜져 있어도 **잠그기** 후에는 학생 저장이 되지 않으므로 수업 중에는 누르지 않는다. 수업을 마칠 때는 **잠그기** 후 **촬영 종료**로 카메라를 멈춘다.

목록에는 학생 번호·이름, 저장 날짜, 길이, 남은 보관 기간이 표시된다. 정보가 손상된 클립은 재생되지 않고 해당 항목만 삭제할 수 있다. 교사 메뉴를 닫으면 목록은 다시 잠기지만, 이미 입력한 교사 키는 **잠그기** 전까지 유지된다. 수업을 마치면 **잠그기**로 교사 키를 끝낸다.

## 7. 화면 잠금·다른 앱으로 이동

수업 중 화면을 잠그거나 다른 앱으로 이동하면 Android가 카메라 또는 프레임 수집을 중단할 수 있다. 이때 앱은 촬영을 멈추고 실시간 버퍼를 비운다.

- 앱으로 돌아오면 **촬영 다시 시작**을 눌러 새로 촬영을 시작한다.
- 중단 전 영상과 다시 시작한 영상은 이어 붙이지 않는다. 중단 구간은 저장할 수 없다.
- 저장 중에 앱을 벗어나 저장이 중단됐다면, 선택 화면을 닫기 전까지 같은 장면을 다시 저장할 수 있다. 선택 화면을 닫으면 그 선택은 사라진다.
- 기기가 지원하면 촬영 중 화면 꺼짐 방지를 요청하지만, 모든 기기에서 보장되지는 않는다.

## 8. 오프라인 사용

앱 셸(화면·스크립트·아이콘 등 정적 파일 14개)이 한 번 정상적으로 준비된 뒤에만 오프라인 실행을 기대할 수 있다.

- 첫 실행은 인터넷 연결이 필요하다. 셸 준비에 실패하면 안내와 **다시 시도** 버튼이 표시된다.
- 셸이 준비된 뒤에는 서버 연결이 끊겨도 이미 캐시된 화면을 열 수 있다.
- PIN과 저장한 클립은 서비스 워커 캐시가 아니라 기기의 IndexedDB에 있으므로, 현재 구현에서는 오프라인에서도 그대로 남는다.
- **실제 Android 기기에서의 설치·비행기 모드 오프라인 실행은 아직 검증하지 않았다.** 개발용 브라우저의 캐시 검사 결과로 실제 기기 동작을 대신하지 않는다.

## 9. 새 버전 안내

새 버전이 준비되면 **새 버전이 준비됐어요** 배너가 표시된다.

- **나중에**를 누르면 배너만 닫힌다. 수업 중 화면은 그대로 사용할 수 있다.
- 앱은 강제로 새로고침하거나 즉시 새 버전으로 전환하지 않는다.
- 현재 구현에서는 새 버전이 앱을 **완전히 닫았다가 다시 열면** 적용된다. 탭만 전환하거나 화면만 새로고침하는 것으로는 적용되지 않을 수 있다. 실제 Android 기기에서의 적용 시점은 아직 검증하지 않았다.
- 현재 구현과 개발용 브라우저 검증에서는 업데이트 후에도 PIN과 저장한 클립이 유지됐다. 실제 기기에서도 업데이트 전후에 목록과 PIN이 정상인지 확인한다.
- 브라우저 저장 데이터를 지우면 PIN과 클립이 모두 사라지므로, 업데이트 문제를 해결하려고 사이트 데이터를 지우지 않는다.

## 10. 보관 한계

| 대상 | 보관 방식 | 한계 |
| --- | --- | --- |
| 임시 영상 | 메모리의 최근 5분 순환 버퍼 | 앱을 닫거나 촬영을 중단하면 사라진다. 저장하지 않은 장면은 복구할 수 없다 |
| 저장한 클립 | 이 태블릿의 IndexedDB | 소리 없음, 최대 30초, 저장 후 7일 만료 |

- 7일 만료는 앱을 열 때, 목록을 확인할 때, 클립을 재생하기 전, 앱 실행 중 주기 점검 때 처리한다.
- **앱이 닫혀 있는 동안 정확한 만료 시각에 삭제되는 것을 보장하지 않는다.** 앱을 다시 열면 그때 만료된 클립을 정리한다.
- 브라우저 데이터 삭제, 기기 초기화, 브라우저의 저장 공간 정리로 7일보다 일찍 사라질 수 있다.
- 교사 메뉴의 **기기 저장 공간**에서 추정 용량을 확인하고 **자동 정리 방지 요청**을 할 수 있지만, 이는 7일 보관을 보장하지 않는다.
- 다른 태블릿이나 클라우드로 자동 백업되지 않는다.

## 11. PIN 분실과 초기화

PIN을 잊으면 **복구할 수 없다.** PIN에서 파생한 키로 클립과 이름·번호를 암호화하므로, PIN 없이 내용을 열 수 없다.

PIN을 잊은 경우:

1. 교사 PIN 화면에서 **PIN 분실 · 기기 데이터 초기화**를 누른다.
2. 새 6자리 PIN을 두 번 입력한다.
3. 확인 문구로 정확히 **`모두 삭제`** 를 입력한다.
4. **모두 삭제하고 새 PIN 설정**을 누른다.

이 초기화는 **이 태블릿의 모든 로컬 클립과 학생 이름·번호를 삭제**하고 새 PIN을 설정한다. 삭제한 클립은 복구할 수 없다. 다른 기기의 데이터에는 영향을 주지 않는다.

이것은 일반적인 PIN 변경이 아니다. PIN만 바꾸면서 기존 클립을 유지하는 기능은 현재 없다. 클립을 남기고 싶다면 PIN을 잊지 않도록 관리해야 한다.

## 12. 수업 전후 확인

수업 전:

- [ ] `{{HTTPS_BASE_URL}}`이 HTTPS로 열리는가
- [ ] 앱을 Chrome 탭 또는 설치된 앱으로 열 수 있는가
- [ ] 교사 PIN으로 카메라를 시작할 수 있는가
- [ ] 카메라 권한이 허용되어 있는가
- [ ] 지연 시간이 수업에 맞게 설정되어 있는가
- [ ] 태블릿이 고정되어 있고 학생 전신이 화면에 들어오는가
- [ ] 저장 공간이 충분한가
- [ ] 설정한 지연 시간만큼 버퍼가 쌓였는가

수업 후:

- [ ] 저장한 클립 목록과 재생을 확인했는가
- [ ] 필요 없는 클립을 삭제했는가
- [ ] **잠그기**로 교사 세션을 끝냈는가
- [ ] **촬영 종료**로 카메라를 멈췄는가
- [ ] 앱을 완전히 닫았는가

## 13. 아직 검증되지 않은 항목

- 실제 Android Chrome에서 앱 설치·홈 화면 추가·standalone 실행
- 비행기 모드에서의 오프라인 실행과 재실행
- 갤럭시 탭 A9+ 및 저사양 기기의 카메라·저장 성능, 발열, 배터리
- 실제 교실에서의 40분 연속 사용과 학생 사용성
