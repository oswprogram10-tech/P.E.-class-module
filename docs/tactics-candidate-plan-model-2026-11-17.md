# 후보 계획: 개발용 Chromium의 실제 3B 모델 실행

2026-11-17에 고정한 독립 요청 두 개와 검색 후보가 없는 통제 요청 한 개를 실행했다. 450문항 모델 평가가 아니며 정답, 정확도, 관련성 또는 성능 개선을 입증하지 않는다. Android 기기나 학교 환경은 검증하지 않았다. 제한된 프로파일은 원본 전체가 아니며, 선택된 자료의 다른 범위·제한과 티볼의 규칙·수업 조건은 원문에서 따로 확인해야 한다.

실제 Qwen2.5-3B-Instruct Q4_K_M 파일 2,104,932,768바이트와 SHA-256 `626b4a6678b86442240e33df819e00132d3ba7dddfe1cdc4fbb18e0a9615c62d`를 확인했다. 새 Chromium 프로필에 로컬 파일을 설치한 뒤 서버를 종료하고 브라우저를 오프라인으로 전환했다. 모델을 모의하지 않았고 외부 요청은 0건이었다. 모델 로드 옵션과 실제 엔진은 2스레드, cgroup CPU 2개, affinity CPU 0–1이었다. 이 하네스의 CPU 제약은 이번 환경 재현용이다. 각 요청에 호스트 측 12분 제한을 두었다. 기록된 소요 시간은 이 개발 환경에 한정된다.

두 요청 모두 검색 8개 중 세 개를 모델에 제시하고 다섯 개를 생략했다. 응답은 각각 제시된 ID 중 두 개이고, 선택 카드의 검색 원본 필드는 보존됐다. 빈 후보 통제는 16ms에 반환했고 모델 로드와 생성 호출은 없었다. 프롬프트 전체, 프로파일, 누락 ID, 출력, 진행률, 호출 설정, 요청과 오류는 [정정 이력이 포함된 기록](tactics-candidate-plan-model-2026-11-17.json)에 있다.

실행 시 하네스가 이전 15문항 실험에서 복사한 잘못된 `sampling` 설명을 기록했다. 실제 sample 배열과 호출은 위 두 독립 요청과 빈 후보 통제였다. 원시 JSON은 [별도 보존](tactics-candidate-plan-model-2026-11-17-raw.json)했으며 정정 기록은 원문 설명과 이유를 함께 보유한다. 실행 당시 하네스 SHA-256은 `0a1694150ee6896d2c056af166296bd3290c2c841e77256a9d654b2d88cd3377`, 설명 정정 후는 `2bd525c2893996c35a0956259a7804fbcca41fc5eeeb38c2d1c7754a57138846`이다. 프롬프트와 advisor의 SHA-256은 실행 전후 각각 `d8c2b3480f4432bc75a955bd8cc718d0f9f90481fa72046c8e68b3c258f91e33`, `63143366c1c5031d2713cb611de27e9fb6a63d8754b165bb02f9848efdca74ea`로 같았다. 새 임시 프로필은 종료 후 삭제됐다.
