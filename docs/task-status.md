**2026-11-17 최신 작업 정책:** AI 구현 단계는 마무리하고 검증은 보류한다. AI 실기기 성능 확인과 AI 선택 품질 검증(전수 모델 생성·전문가 재평가 포함)은 현재 진행 대상에서 제외하여 마지막 통합 검증으로 옮긴다. 검증 완료나 품질 통과로 승격하지 않으며 추가 학습을 필수 새 작업으로 만들지 않는다. 40분 연속 사용·발열·학교 환경 확인은 기존대로 교사 첫 사용 점검에서 진행한다. 아래의 우선순위와 남은 검증 기록은 당시 이력을 보존한다.

**2026-11-17 응답 준비 개선:** 성공한 기기 AI 실행 후 잠시 모델을 재사용하고 초기화·잠금·화면 종료와 명시적 메모리 비우기에서 해제하도록 연결했다. 실제 앱 3B 단일 측정에서 첫 실행은 변경 전 457.09초, 변경 후 454.60초, 30초 내 동일 질문 재실행은 24.29초였다. 다른 질문의 재사용은 353.40초였다. 각각 Chromium CPU 환경에서 한 번 측정한 결과이며 선택 품질과 학교 기기 검증은 남아 있다. 관련 단위·CLI 검사 64개, 모의 엔진의 실제 브라우저 두 탭 잠금 검사, Android 빌드·단위 검사·Lint와 APK 75개 파일 바이트 비교가 통과했다. ## S4.5 — 학생·수업별 최소 동작 이력 (2026-11-06)

교사가 켠 때에만 실제 동작 이벤트의 최소 근거 요약을 S3 PIN 암호화 학급 저장소에 기록한다. 현재 바인딩의 학급·학생·수업·기기 ID, 입력 시각, 선택 팔·민감도·2D 팔꿈치 각도·손목/몸통 비율, 신뢰도 요약·감지 기준·모델 버전을 저장한다. 이름·PIN·이미지·전체 관절 좌표와 네트워크 전송은 포함하지 않는다. 기록은 최대 7일이며 부모 자료 만료·삭제와 연결 클립 만료에 맞춰 삭제한다. 교사 PIN 이력 조회·개별 삭제와 명시적 같은 범위 클립 연결을 제공한다.

`node --test tests/*.test.cjs`의 59개 단위 검사와 브라우저 17종이 통과했다. `node tests/browser-shot-history.cjs`에서 기본 꺼짐·PIN 암호화 저장·조회·삭제·같은 범위 클립 직접 연결·빈 outbox를 확인했고, 기록 동작은 합성 시퀀스로 공급했다. `node tests/browser-shot-history-failures.cjs`에서 실제 IndexedDB의 put 전 취소, 주입한 quota 오류 뒤 fake camera 프레임 지속, 암호화 대기 중 중단을 확인했다. 실 저장소 용량 초과, 실제 농구 슛 정확도와 Android·학교 환경·40분·발열은 미확인이다. 근거는 [S4.5 사용 안내](S4-history-guide.md)와 [검증 기록](stage-S4-history-validation.md)를 따른다. 다음은 S4.6 정확도·자원 사용 검증이다.


## S4.6 — 정확도 평가·자원 계측의 로컬 준비 (2026-11-06)

합성/정의 fixture 7개를 순수 규칙에 넣는 standalone harness, 일대일 사건 매칭·TP/FP/FN·precision/recall·방향/조건별 micro 집계, Node CPU·RSS/heap 측정을 추가했다. 합성 결과 TP 3·FP 1·FN 2 (0.75/0.6)는 현장 정확도가 아니다. 단위 전체 64개와 Luna의 매칭 6,400 조합 검사가 통과했다. production 앱·셸 변경이 없어 기존 브라우저 전체는 이번에 재실행하지 않았다.

상태는 **로컬 준비 완료, 실제 검증 대기**다. 기존 real-model JSON을 보존하며 Android·발열·40분·동의된 실제 자료·교사 검토는 미실행으로 유지한다. 세부 명령·수치·sandbox 제약은 [검증 기록](stage-S4-evaluation-validation.md), 실제 자료/기기 검증 방법은 [평가 절차](S4-evaluation-protocol.md)를 따른다. 게시·배포·commit·push하지 않았다.


## S4.6 후속 — 배구 연습 cue·모델 프로필 (2026-11-06)

실험용 로컬 개발 기능 구현: 배구 머리 위 팔 동작의 독립 type/ruleVersion, 세션 한정 종목·팔·사용 선택, 종목 변경 시 준비/추가 피드백/이력 중단, 농구 이력 분리. 모델 프로필 로더는 기존 공식 Lite의 동일 출처·SHA pins만 허용한다. 대체 licensed weights가 없어 대체 모델 통합은 미실행이고 확장 인터페이스만 제공한다. 기존 S4.6 농구 합성 평가를 배구 정확도로 인용하지 않는다.

단위 71개 통과. 구체 브라우저 결과와 남은 범위는 [종목 확장 검증](stage-S4-sport-extension-validation.md)에 기록한다. 실제 스포츠 정확도·교사 검토는 미확인이고 Android·학교 환경·발열·40분 연속 사용은 사용자 지시로 이번 범위에서 제외·대기다. 기존 dirty 변경·농구 저장 설정을 보존하고 게시하지 않았다.


## S5.1 — PAPS 수기 기록·수정 이력 (2026-11-06~07)

`measurements`에 학년도·S3 학생 ID·측정일·종목·원값/단위·입력/수정 시각·기준 버전을 별도로 저장한다. 교사 PIN 암호화 로컬 저장만 사용하고 기존 7일 클립 정리와 분리했다. 5개 기초 수기 항목, 단위·기술 범위·소수 자릿수 검사, 6개 결측 사유, 동명이인 ID 구분, 연속 학생 입력, 변경 이력, 기록별/학급별 삭제를 제공한다. 수정은 이전 값·새 값·시각·교사 역할을 이력에 남기며 학생 ID와 학년도는 고정한다. 학년도 만료와 측정값 삭제 때 이력도 함께 정리한다. 기록은 학년도 기준 최대 세 학년도 보관하며 학생·학급 식별 정보도 연결 기록과 같은 시한 동안 암호화 유지한다. PIN 초기화 취소·실패는 클립·측정값·수정 이력을 보존하고 성공은 새 PIN과 함께 모두 삭제하는 것을 확인했다. 기준 버전은 미지정이고 PAPS 점수·등급·백분위·건강 판정은 계산하지 않는다.

단위 모델·보관 검사와 측정 입력, 초기화, 학급 흐름/개인정보, PWA 브라우저 검사를 통과했다. 새 흐름에서 동명이인 연속 입력, 결측, 이전/새 값 이력, 암호문 저장, 개별·학급 삭제, PIN reset rollback/성공 및 이전 탭 키 거부를 확인했다. 전체 회귀는 재실행하지 않았다. 규칙 제7조제3항의 요소별 1종목 선택과 별지 제1호서식 뒤쪽의 요소-종목 집계를 적용했다. 심폐지구력, 유연성, 근력·근지구력, 순발력, 비만도의 다섯 요소에 대해 학급·학년도별 검사 한 종목을 교사가 선택하고, 학급·학년의 등급 기준에 맞지 않는 선택은 차단한다. 오래달리기-걷기는 초5·초6 1,000m 또는 중·고의 성별 거리로, 팔굽혀펴기는 남자 일반/여자 무릎대고 검사로 실제 측정 항목을 대응한다. 설정과 이전 선택 이력은 PIN 암호화 상태로 보존하며, PAPS 원자료와 같은 3개 학년도 경계를 갖는다. BMI는 선택 가능하지만 정확한 점수표가 제공되지 않아 이 기능은 배점·종합점수·종합등급을 만들지 않는다.

`node --test tests/*.test.cjs` 144개, `node tests/browser-paps-reports.cjs`, `node tests/browser-classroom-measurements.cjs`, `node tests/browser-pwa.cjs`, 편집한 JavaScript 구문 검사와 `git diff --check`가 통과했다. 요소별 선택과 성별 항목 대응, 저장/수정 이력, 학급 삭제와 이전 상태 기본값을 단위 검사했고, 개발용 Chromium에서 설정 UI와 오프라인 v29 앱 셸을 확인했다. 학교 현장 검증은 별도다. 게시·배포·commit/push는 하지 않았다.

## S5.2.10 — NEIS BMI 세부 점수 기준 조사 (2026-11-07)

별표 5는 BMI 정상 점수 20점과 저체중·비만 방향을 제시하면서 세부 배점을 NEIS 종목별 상세 점수 기준에 위임한다. 제공된 규칙 PDF와 첨부 저장소 문서에서 해당 세부 표를 찾지 못했다. 공식 법령 사이트 요청은 클라우드 프록시에서 403/502로 차단됐고, 이 실패는 기준이 존재하지 않는다는 결론을 뒷받침하지 않는다. 공식 원문 확보 전까지 BMI 항목점수, 100점 합계와 종합등급은 계속 미산출한다. 이번 단계는 문서 조사만 수행했고 앱 코드는 변경하거나 게시하지 않았다. [조사 기록](stage-S5.2.10-bmi-score-research.md).

## S5.2·S5.5 — PAPS와 나이스 공식 자료 대조 (2026-11-18)

국가법령정보센터 별표 5·6의 합산 및 종합등급, 경기교육청 나이스 매뉴얼의 종목별 백분위 조회와 파일 입출력 절차를 대조했다. BMI 세부 배점과 종합 결측 처리, 백분위 산식, 실제 PAPS 및 학교생활기록부 파일 구조는 확인 대기다. 신체발달 건강검사의 성별·연령별 BMI 백분위수 근거는 별표 1로 바로잡았다. [공식 자료 대조](S5.2-S5.5-official-data-audit.md)

교사 문안 작성·편집에서 2026학년도 고교 과목별 세특의 1,500바이트 기준과 UTF-8 추정 분량을 표시한다. 초과량을 안내하며 로컬 문안 저장과 승인 CSV는 기존 절차를 따른다. 단위 테스트 219개와 교사 문안·PAPS 보고 Chromium 검사, Android 교사 APK 조립·단위 검사·Lint가 통과했다. PWA 셸을 v56으로 갱신했다. PWA 전체 검사는 앞선 두 실행에서 가상 카메라 저장 시간 초과와 재생 길이 오차(5.118초, 상한 5.1초)가 각각 있었고, 세 번째 실행에서 통과했다.

## 교사 첫 사용 설정 (2026-11-18)

첫 PIN을 만들면 40분 기기 점검과 함께 수업에 필요한 설정 화면을 바로 열 수 있다. 지연 재생, 학급, PAPS, 루브릭·성취기준, 운동 루틴, QR·GPS, 전술판 공유, 기기 AI, 학급 제출 서버와 웨어러블은 실제 기능 화면으로 연결한다. 학급이 필요한 경우 먼저 생성 또는 선택하도록 안내한다. 서버 운영과 Apple 빌드·서명, 나이스 공식 자료 확인은 담당 환경이 준비되어야 한다. [교사 첫 사용 설정 안내](first-use-device-check.md)

가상 카메라 검사에서 첫 프레임이 오기 전에 타이머가 돌던 문제를 발견해 첫 유효 프레임부터 시간을 재도록 수정했다. 단위 검사 219개, 첫 사용·레이아웃·교사 도구·PWA 브라우저 검사, Android 교사 APK 조립과 단위 검사·Lint가 통과했다. PWA 셸은 v57이다. 실물의 40분 사용·발열·학교 환경 결과는 교사가 기록한다.

## 학교 1차 출시 범위 (2026-11-18)

이번 출시 목표를 **교사 기기에 정보 저장 · 학교 서버 운영**으로 정했다. 첫 사용 설정과 출시 안내에 웨어러블 정식 연동, 공식 PAPS·나이스 연동, 동작 분석과 검토된 운동 콘텐츠, AI 전술 제안의 정식 지원을 **미구현**으로 표시한다. Caddy가 공개하는 기능은 학급 제출·동기화와 전술판 공유다. PWA 셸은 v58이다. [학교 1차 출시 안내](release-runbook.md)

`school-v1-rc1`의 94개 파일을 묶고 해시를 검증했다. 시험용 HTTPS에서 AI 제안·학습 예제 차단, 학급 인증·선택 제출, 암호화 전술판 공유, 서버 재시작 후 자료 보존을 확인했다. 교사·학생 역할별 격리 Chromium 프로필로 오프라인 대기열·응답 유실·재시도·철회도 확인했다. 통합 브라우저 리허설은 시험용 HTTPS에서 활성 서비스워커가 새 페이지를 제어하지 못해 중단됐다. 로컬 HTTP의 PWA 오프라인 재실행·업데이트 검사는 가상 카메라 저장 지연 후 재시도에서 통과했다. 실제 학교 HTTPS 배포와 물리 기기 연결 확인은 남아 있다.
