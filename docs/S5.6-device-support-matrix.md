# S5.6 웨어러블 출시일·모델·OS 확인표

조사일은 **2026-11-17**, 출시일 하한은 사용자가 정한 **2022-11-07(당일 포함)**이다. 아래 항목은 제조사 자료에서 확인한 연결 시험 후보다. **PE Loop에서 실기기 연결을 검증한 모델은 아직 없다.**

- 학생 휴대폰과 워치가 [공통 모델 목록](../native/android/shared/src/main/java/com/peloop/wearable/GalaxyWatchCatalog.kt)을 사용한다. F·N·U 접미사를 가진 모델은 공식 확인한 문자열만 개별 등록했다. 소매 SKU 전체와 임의 접미사는 연결 판정에 쓰지 않는다. [삼성 모델·펌웨어 표](https://www.samsung.com/jp/support/mobile-devices/please-tell-us-about-the-latest-version-of-the-galaxy-watch/) · [삼성 매뉴얼의 LTE 모델](https://www.samsung.com/jp/support/mobile-devices/how-to-check-the-online-manual-of-open-products/) · [미국 모델별 삼성 자료](https://www.samsung.com/global/sustainability/policy-file/AYmutOga96AALYNW/LCA_Results_for_Watch.pdf) · [삼성 한국 Ultra2 모델 번호](https://www.samsung.com/sec/support/model/SM-L715NZSAKOO/) · [삼성 이스라엘 변형 표](https://www.samsung.com/il/support/screen-replacement-pricing0/)
- Watch FE LTE는 제조사 자료로 제품과 SM-R866U를 확인했다. 판매 안내에 예약과 판매 표현이 혼재해 첫 정규 판매일을 확정하지 못했고 Bluetooth 출시일을 적용하지 않았다. 앱에서는 날짜 확인 대기로 둔다. Watch Ultra 2025 변경 모델은 같은 SM-L705 계열로 확인돼 코드에서 최초 세대 날짜를 유지한다. [삼성 FE LTE 안내](https://news.samsung.com/us/galaxy-s24-series-expands-with-s24-fe-a-premium-experience-that-makes-full-galaxy-ai-capabilities-attainable-for-more-users/) · [삼성 Ultra 2025 모델](https://www.samsung.com/sec/support/model/SM-L705NZB1KOO/)
- Watch5·Watch5 Pro는 [2022-08-26](https://news.samsung.com/global/samsung-leads-holistic-health-innovation-with-galaxy-watch5-and-galaxy-watch5-pro)에 판매를 시작해 날짜 하한 밖이다.
- 워치는 측정 시작 전에 실제 워치 SDK와 페어링 휴대폰이 보낸 SDK를 확인한다. 학생 휴대폰은 워치가 준비 응답을 보낼 때 워치 SDK와 자신의 SDK를 다시 검사한다. 워치·휴대폰 앱을 함께 업데이트해야 한다. FE는 출시 자료가 Wear OS 세부 번호 대신 One UI 5 Watch를 명시하므로 앱 공통 Wear OS 3/API 30 하한을 사용한다. [Google Health Services 호환성](https://developer.android.com/health-and-fitness/health-services/compatibility) · [Wear OS 6/API 36](https://developer.android.com/training/wearables/versions/6/changes) · [Wear OS 7/API 37](https://developer.android.com/training/wearables/versions/7/changes)

## 실기기에서 올릴 상태

확인할 조합에는 워치 모델 번호와 내부 ID, 실제 OS·휴대폰 모델·OS, 실시간 심박 권한과 센서, 첫 표본, 화면 꺼짐·끊김·재접속, 교사 태블릿까지의 연결이 포함된다. 실제 시험이 끝나면 기기별 결과를 기록한다. Apple 빌드·서명에는 macOS/Xcode가 필요하다. [검증 기록](stage-S5.6-wearable-validation.md) · [LAN 연결 계약](S5.6-lan-relay-contract.md)
