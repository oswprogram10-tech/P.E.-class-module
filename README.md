# PE Loop · 셀프 리뷰 PWA

안드로이드 태블릿을 거치해 쓰는 초등 체육 수업용 지연 카메라 MVP입니다. 원본 카메라 스트림은 브라우저 안에서 처리합니다. 학생이 직접 선택한 클립·성찰만 선택적으로 개발용 loopback 허브에 제출할 수 있습니다.

상세 작업·예상 일정·완료 기준은 [구현 계획표](docs/implementation-plan.md)에 정리했습니다. 현재 코드는 실제 태블릿 검증 전인 초안입니다.

0·1·2·3단계의 현재 진행 상태는 [작업 상태표](docs/task-status.md), 화면 흐름은 [A01](docs/A01-screen-flows.md), 상태·모듈 설계는 [A02](docs/A02-state-and-modules.md), 기기 지원 기준은 [A03](docs/A03-support-matrix.md)에 기록합니다.

후속 개발은 [세션 목표](docs/session-goals.md)의 순서를 따릅니다. S1의 설치·오프라인 준비·업데이트·복구·버전 복귀 절차는 [교사·운영 안내](docs/S1-release-guide.md), 실행 근거와 실기기 대기는 [S1 검증 기록](docs/stage-1-validation.md)을 확인하세요.

S2의 장면 선택·비교·성찰·300초 지연은 [사용 안내](docs/S2-review-guide.md)와 [S2 검증 기록](docs/stage-S2-validation.md)에 정리했습니다. 실제 Android 검증은 대기 중입니다. S3 학급·선택 제출·피드백의 로컬 사용과 개발 허브 범위는 [S3 사용·운영 계약](docs/S3-data-and-sync.md), 실행 근거와 한계는 [S3 검증](docs/stage-S3-validation.md)을 따릅니다.

S4.1~S4.2의 공식 Lite 모델·이용조건 근거·실제 추론·offline 및 짧은 카메라 동시 검증에 이어, S4.3 농구 READY→SHOOT 동작 감지를 구현했습니다. 교사 PIN 안에서 사용하는 팔과 민감도를 설정하며, 전신 확인이 끊기거나 설정·수업 맥락이 바뀌면 다시 준비해야 합니다. 골 성공·슛의 정확성·성적을 판정하지 않습니다. [전신 확인 안내](docs/S4-foundation-guide.md), [농구 동작 안내](docs/S4-shot-guide.md), [S4.3 검증 기록](docs/stage-S4-shot-validation.md)을 확인하세요. S4.3 개발 검증을 완료했으며, Android·학교 환경·40분 실행과 현장 정확도는 대기 중입니다. 기존 촬영·지연·클립 흐름은 유지됩니다.

S4.4의 시각 강조·효과음·순간 이미지는 선택 기능이며 기본 꺼짐입니다. 이미지는 실제 추론 입력 프레임에서 만들고 최신 1장만 메모리에 둡니다. S4.5에서는 교사가 별도로 켠 경우 감지 이벤트의 최소 각도·근거 요약을 S3의 PIN 암호화 로컬 학급 데이터에 최대 7일 기록합니다. 원시 이미지·전체 관절 좌표와 자동 허브 전송은 포함하지 않습니다. 조회·삭제·같은 학생·수업·기기의 클립 연결은 [S4.5 동작 이력 안내](docs/S4-history-guide.md)와 [검증 기록](docs/stage-S4-history-validation.md)을 확인하세요. 개발 검증은 완료했으며 실제 Android·학교 환경·장시간·스포츠 정확도는 미확인입니다.

S4.6의 합성 평가 harness와 규칙 모듈 개발용 자원 계측을 준비했습니다. 정의된 7개 사례에서 TP 3·FP 1·FN 2를 집계하며 실제 농구 정확도를 뜻하지 않습니다. [평가 절차](docs/S4-evaluation-protocol.md)와 [S4.6 검증 기록](docs/stage-S4-evaluation-validation.md)에 재현 명령·방향/조건별 결과·실기기 대기를 구분했습니다.

배구 머리 위 팔 스윙 연습 cue와 승인된 모델 프로필 로더 인터페이스를 실험 기능으로 추가했습니다. 종목 선택은 이번 실행에만 적용하고 배구 cue를 농구 이력으로 저장하지 않습니다. 모델은 기존 공식 Lite 하나만 지원합니다. [사용·한계](docs/S4-sport-extension-guide.md)와 [검증 기록](docs/stage-S4-sport-extension-validation.md)을 확인하세요.

## 현재 기능

- 전면 카메라를 480×270, 무음으로 캡처해 최근 5분의 프레임을 메모리에 순환 보관합니다.
- 교사가 1~300초 지연 시간을 설정합니다. 기본값은 20초입니다. 실제 보관 범위·바이트 한도가 부족하면 안내하며, 300초의 경계 샘플 오차는 실제 촬영 시간이 지난 뒤 최대 150ms만 허용합니다. Linux 가상 카메라의 실제 310초 검증과 Android 지원 보장은 구분합니다.
- 실제 지연 화면에 표시된 장면을 선택의 기본 끝 경계로 고정하고, 확보된 프레임으로 시작·끝을 조절해 5~30초의 무음 클립을 저장합니다. 시작 포함·끝 경계 제외이며 소수 초 길이를 지원합니다. 영상 부족·누락·상한을 검사합니다.
- 잘된 점·다시 시도할 점을 암호화 메타데이터로 남기고, 교사 목록에서 속도·반복을 조절합니다. 명시적 파일 내보내기에는 교사 접근·동의·만료 검사를 적용하며 평문 파일의 보관은 앱 밖에서 관리합니다.
- 로컬 시범 영상을 겹치거나 나란히 놓고 투명도·크기·위치·시점을 조절합니다. 화면 비교만 제공하며 시범 영상을 저장 클립에 합성하거나 외부로 전송하지 않습니다.
- 학생 이름과 번호를 입력해 클립을 구분합니다. 저장된 WebM 클립은 IndexedDB에 로컬 저장되고 앱을 열거나 목록을 확인할 때 7일 만료를 정리합니다.
- 교사는 첫 실행 시 6자리 PIN을 만듭니다. 수업을 시작할 때 PIN을 입력하고, 저장된 클립 목록을 열 때도 PIN을 입력합니다. 영상과 학생 이름·번호는 PIN에서 파생한 AES-GCM 키로 암호화합니다. 잘못된 PIN이 기존 수업 키를 지우지 않고, 목록 닫기와 명시적 잠금은 별도로 처리합니다.
- PWA 셸은 서비스 워커 캐시로 오프라인에서 열 수 있습니다. 카메라와 보안 저장 기능의 초기 설정에는 HTTPS가 필요합니다.
- 오프라인 준비 안내는 필수 셸 캐시를 실제로 확인합니다. 새 버전은 수업 도중 강제 활성화하지 않고, **업데이트 준비** 안내에 따라 모든 앱 창을 닫고 다시 열 때 적용합니다. 기존 v5에서 처음 전환할 때도 수업을 마친 뒤 모든 창을 종료·재실행하세요.

- 학급·학생·수업·모둠·기기를 ID로 지정하고 대표 클립/성찰을 직접 선택해 암호화 대기열에 담습니다. 교사 관찰·이력, 개발용 허브 QR 참여·모드, 승인형 칭찬·텍스트 피드백을 지원합니다. 기존 이름·번호 클립은 미배정으로 유지하며 자동/수동 이관은 제공하지 않습니다.
- 교사 PIN으로 잠긴 학급 영역에서 PAPS 기초 체력 항목 5종을 학년도·측정일·S3 학생 ID와 연결해 기록할 수 있습니다. 교사가 학년과 남자/여자 평가표를 직접 선택하면 2026학년도 별표 4의 해당 종목 등급을 미리 보고, 선택 범위와 기준 버전을 원자료·수정 이력과 함께 로컬 암호화 저장합니다. 학생을 바꾸면 기준 선택은 초기화됩니다. 전체 입력 등급 기준은 [S5.2 출처 기록](docs/S5.2-criteria-sources.md)에 있습니다.
- PAPS 기록은 최대 3개 학년도 보관, 개별·학급 삭제를 지원합니다. PIN 초기화는 이 기록과 이력을 함께 삭제합니다. 결과는 종목별 기준 등급이며 PAPS 종합점수·백분위·BMI 판정·건강 진단·NEIS 출력이 아닙니다. 일부 학년의 평가 의무 여부는 규칙을 따릅니다.
- 교사 PIN 영역에서 명시적 학생·종목·학년·평가표를 고른 PAPS 추이와 학급 등급 분포를 볼 수 있습니다. 선택한 원자료는 확인 후 로컬 CSV로 받을 수 있으며 NEIS 양식이 아닙니다.
- 여섯 개 자체 텍스트 운동 안내와 3+6+6분 타이머를 제공합니다. 교사가 각 안내의 안전 주의와 학급 적합성을 직접 체크해야 사용할 수 있으며, 전문가 검증이나 개인 건강 처방을 뜻하지 않습니다.
- 교사 자체 지식·기능·태도 루브릭, 관찰/성찰/직접 제출 근거 연결, 수기 평가 승인, 교사가 직접 쓰는 승인 문안과 로컬 임시 CSV를 지원합니다. 공식 교육과정 매핑·NEIS 파일·생성형 AI는 포함하지 않습니다.
- 순서형 퀴즈/활동을 익명 QR 미션으로 만들고 오프라인 응답을 로컬 암호화 저장소에 보관합니다. 응답에 학생 ID·이름·위치를 연결하지 않습니다. QR 카메라 읽기를 지원하지 않는 브라우저는 무작위 ID 직접 입력을 사용합니다.
- 익명 토큰·좌표·이동/패스·공격/수비 표식으로 수동 전술판을 만들고 실행 전후 스냅샷과 회고를 저장합니다. 기기간 공유나 AI 전술 추천은 없습니다.
- 웨어러블 선행 기반은 2022-11-07 이후 출시 Galaxy Watch/Apple Watch의 심박 전용 PWA 브리지 v2와 Android 태블릿 호스트 앱입니다. Android API 35 debug APK를 빌드했고 단위 검사·Lint가 통과했습니다. 태블릿 설치·실제 LAN 연결과 학생 companion의 자동 재시도·서비스 탐색은 아직 검증되지 않았습니다. 심박값과 재접속 자격은 세션 메모리만 사용합니다. 자세한 범위와 한계는 [웨어러블 검증 기록](docs/stage-S5.6-wearable-validation.md)에 있습니다.
- 개발용 허브는 같은 컴퓨터의 RAM에 선택 자료를 평문 보관합니다. 실제 학생 자료 운영·LAN/HTTPS·영속 암호화 서버 배포는 완료하지 않았습니다.

## 이번 안정화 작업

- 촬영·구간 선택·저장 중 상태를 명시하고 저장 중 중복 클릭, 구간 수정, 닫기를 차단합니다.
- 미리보기와 인코딩용 캔버스를 분리합니다. 선택 화면을 열 때 버퍼를 스냅샷으로 고정해 입력 중 장면이 이동하지 않습니다.
- WebCodecs VP8 인코더와 WebM 작성기로 원본 시각을 10fps 출력 시각에 맞춥니다. 선택한 5·15·30초가 실제 파일에서도 같은 길이가 되며, 출력의 최대 길이는 30초입니다. 이 인코더를 지원하지 않는 기기에는 업데이트·지원 안내를 표시합니다.
- 저장 중에는 명시적으로 취소할 수 있습니다. DB 커밋 중에는 취소 버튼을 비활성화하고, 실패 시 같은 선택과 입력으로 재시도합니다. 이름은 1~24자, 번호는 1~9999 범위의 숫자로 확인합니다.
- 설정한 지연 시간이 쌓일 때까지 남은 시간을 표시합니다. 저장 중 앱이 백그라운드로 이동하면 결과를 저장하지 않고 재시도를 안내합니다.

## 개발 검증

`node --test tests/timeline.test.cjs`로 누락 프레임과 경계 시각 선택을 확인합니다. Playwright가 설치된 개발 환경에서는 `node tests/browser-smoke.cjs`로 가상 카메라, PIN 설정, 지연 대기, 구간 고정, 저장 잠금 및 5초 암호화 클립 생성 흐름을 검증합니다. `CHROMIUM_PATH`로 사용할 Chromium 경로를 지정할 수 있습니다. 이 검증은 실제 Android 기기 성능 검증을 대신하지 않습니다.

## 설치와 사용

정적 파일을 HTTPS가 적용된 웹 서버에 올린 뒤 안드로이드 태블릿의 Chrome에서 엽니다. 카메라 권한을 허용하고 Chrome 메뉴에서 **앱 설치** 또는 **홈 화면에 추가**를 선택합니다. 로컬 미리보기는 `localhost`에서 열 수 있습니다.

서비스 워커는 정적 셸만 캐시합니다. 수업 중에는 화면이 켜져 있고 앱이 전면에 있어야 5분 버퍼가 안정적으로 유지됩니다. 다른 앱으로 전환하거나 화면을 잠그면 Android가 카메라/프레임 수집을 중단할 수 있습니다.

앱이 화면에서 벗어나거나 카메라 연결이 끊기면 촬영을 중단하고 실시간 버퍼를 비웁니다. 복귀 후 **촬영 다시 시작**을 눌러 새 촬영을 시작합니다. 새 촬영과 이전 촬영 사이의 중단 구간을 이어 붙이지 않습니다. 이미 선택한 클립은 선택 화면을 닫기 전까지 유지되므로 저장 중단 후 같은 구간을 다시 저장할 수 있습니다. 기기가 지원하면 촬영 중 화면 꺼짐 방지도 요청합니다.

실시간 프레임 버퍼는 5분·3,001프레임·80MiB 중 먼저 도달하는 제한을 적용합니다. 선택 중인 영상 스냅샷과 브라우저 자체의 메모리는 이 프레임 예산과 별도입니다. 실제 기기 전체 메모리·발열 검증은 남아 있습니다. 기준 기기는 **갤럭시 탭 A9+**이며, 실제 사용할 모델의 메모리 용량·Android·Chrome 버전은 확보 후 기록합니다.

## 저장 및 개인정보

클립·학급·측정 기록은 현재 태블릿의 IndexedDB에만 존재합니다. PIN은 학생 공유용이 아니라 교사용으로 관리해야 합니다. PIN을 잊으면 암호화된 로컬 자료를 복구할 수 없습니다. PIN 분실 화면에서 새 PIN 두 번과 ‘모두 삭제’ 확인 문구를 입력해 로컬 자료를 지우고 초기화할 수 있습니다. 클립·학급 암호문 삭제와 새 PIN 설정은 한 트랜잭션으로 처리하며, 취소·실패 시 기존 자료와 PIN을 함께 보존합니다. 앱 데이터 삭제, 브라우저 저장 공간 정리 또는 태블릿 교체는 로컬 자료를 제거합니다.

이 MVP는 학생 명단, 계정, 동기화, 클라우드 백업, NEIS 연동을 포함하지 않습니다. PWA 설치와 카메라 동작, WebCodecs VP8 인코딩은 실제 학교 Android 태블릿과 Chrome 버전에서 현장 점검이 필요합니다.

2단계의 구현·검증 범위와 실제 기기에 남은 확인 항목은 [클립 선택·저장 검증](docs/stage-2-validation.md)에 정리했습니다.

## 3단계 데이터 보호

PIN 설정과 암호화된 클립은 IndexedDB 버전 2에 보관합니다. 이전 버전의 PIN 설정과 암호문은 보존 이전하며, localStorage에는 지연 설정 등 비밀이 아닌 값만 둡니다. 목록에서는 손상 파일을 격리하고 고른 영상 하나만 복호화합니다. 닫기·다른 영상 선택 시 플레이어와 Blob URL을 정리합니다.

만료 파일은 목록·재생 전에 정리하고, 실행 중 다음 만료 시각에도 확인합니다. 기기 시계와 OS 실행 상태에 의존하므로 앱이 닫힌 동안 정시 삭제를 보장하지 않습니다. 생성·만료 정보가 손상된 항목은 재생을 막고 교사가 삭제할 수 있도록 표시합니다.

교사 설정에서 사이트 저장 공간의 추정값과 정리 방지 상태를 확인할 수 있습니다. 이는 7일 보관 보장이 아니며 브라우저 데이터 삭제·기기 초기화로 자료를 잃을 수 있습니다. DB 업데이트가 막히면 다른 이전 앱 탭을 닫고 다시 실행해 주세요.

검증 명령:

- `node tests/browser-data.cjs`: PIN 수명·손상 파일·늦은 응답·삭제·만료·저장 공간 오류.
- `node tests/browser-vault-migration.cjs`: 이전 버전 데이터 이전과 PIN 설정 손실·초기 설정 실패·취소.
- `node tests/browser-reset.cjs`: 명시적 초기화·원자적 실패 복구·다른 탭의 오래된 키 거부.

전체 근거와 실제 기기에 남은 항목은 [3단계 검증 기록](docs/stage-3-validation.md)을 확인하세요.
